■ 이 매뉴얼을 읽는 방법

- 각 절은 「절차」와 「Check Point」로 되어 있다. 절차는 화면에서 순서대로 하는 일이고,
  Check Point 는 그 화면에서 자주 막히거나 헷갈리는 조건을 정리한 것이다.
- 버튼이 안 보이거나 목록에 건이 나타나지 않을 때는 먼저 해당 절의 Check Point 를 확인한다.
  대부분 "앞 단계가 결재완료되지 않았다" 또는 "그 역할이 아니다" 둘 중 하나다.
- "※ 확인 필요"로 표기한 항목은 이전 매뉴얼 내용을 그대로 옮긴 것으로,
  실제 화면과 다를 수 있으니 사용 전에 확인이 필요하다.
- 본문 내용을 시스템에서 어떻게 확인했는지는 별도의 개발자용 자료로 관리한다
  (사용자 배포본에는 포함되지 않는다).


# 1. 개요

1.1 시스템개요

CPMS(Contract & Project Management System)는 공사 계약의 의뢰부터 계약품의까지의 과정을
관리하는 시스템이다. 본 매뉴얼이 다루는 범위는 그중 **계약관리 메뉴**이며,
계약의뢰 → 계약사전보고 → 입찰안내 → 현장설명회 → 질의응답 → 입찰 → 평가/업체선정 →
계약품의 순으로 이어지는 업무를 대상으로 한다.

Check Point
1. 계약 업무는 앞 단계의 결재가 완료되어야 다음 단계 화면에 건이 나타난다.
   저장만 해두고 상신하지 않으면 다음 담당자에게 보이지 않는다.
2. 한 사용자가 여러 역할을 함께 가질 수 있으며, 역할에 따라 같은 화면이라도
   보이는 버튼과 조회되는 건이 달라진다. 자세한 내용은 1.6 을 참조한다.

※ 확인 필요 — 시스템 구성(서버, 연계 시스템 등)은 이전 매뉴얼 내용을 그대로 유지하였다.


1.2 메뉴구성도

계약관리 메뉴는 다음과 같이 구성된다. 괄호 안은 그 메뉴를 주로 사용하는 역할이다.

  계약관리
   ├ 계약의뢰
   │   └ 계약의뢰서 List ................. (계약의뢰자 / 계약진행자)
   ├ 계약사전보고
   │   └ 계약사전보고 List ............... (계약진행자)
   ├ 입찰안내
   │   └ 입찰안내서 List ................. (계약진행자 / 업체담당자)
   ├ 현장설명회 관리
   │   └ 현장설명회 결과 List ............ (계약진행자)
   │       ※ '현장설명서 List' 는 현재 메뉴에 없다. 3.4 (1) 안내 참조
   ├ 질의응답
   │   └ 질의응답 List ................... (계약진행자 / 업체담당자)
   ├ 입찰등록
   │   └ 입찰 List ....................... (계약진행자 / 업체담당자)
   ├ 평가/업체선정
   │   └ 평가/업체선정 List .............. (계약진행자 / 기술평가위원 / 환경안전 평가위원)
   ├ 계약품의
   │   └ 계약품의 List ................... (계약진행자)
   └ 계약현황
       ├ 계약진척현황
       ├ 계약진척현황 조회
       ├ Area별 계약현황
       ├ 유형별 계약현황
       ├ 상태별 계약현황
       ├ 월별 계약현황
       └ 입찰 진행현황 .................... (계약진행자)

Check Point
1. 목록 화면에 들어갈 수 있다고 해서 모든 건이 보이는 것은 아니다. 대부분의 목록은
   본인이 등록했거나 본인이 담당자로 지정된 건, 그리고 결재가 완료된 건만 조회된다.
2. 화면에 따라 표(그리드) 모양이 서로 다를 수 있다. 시스템에 화면 구성이 다른 두 가지
   버전이 함께 있기 때문이며, 조회 조건과 버튼은 동일하게 동작한다.
3. '입찰 진행현황'은 다른 계약현황 화면과 화면 구성이 다르다.
4. '입찰대상 공사관리', '현장설명서 템플릿' 화면은 시스템에는 있으나 이전 매뉴얼
   목차에 없다. 메뉴에 표시되는지 확인이 필요하다(부록 A 12 참조).


1.3 CPMS 접속 URL

※ 확인 필요 — 접속 주소는 이전 매뉴얼의 URL을 그대로 사용한다.


1.4 CPMS ~ KNOX PORTAL 결재 연계 PROCESS

계약관리의 각 문서(계약의뢰서, 계약사전보고, 현장설명회 결과, 계약품의 등)는 화면에서
[Submit] 버튼으로 결재를 상신하며, KNOX PORTAL에서 결재가 처리되면 그 결과가 문서의
진행상태에 반영된다.

진행상태는 모든 문서가 공통으로 다음 5가지를 사용한다.

| 진행상태 | 의미 | 이때 할 수 있는 일 |
|---|---|---|
| 작성중   | 저장만 해둔 상태            | 수정 · 삭제 · 상신 |
| 결재중   | 상신하여 결재가 진행 중     | 없음 (조회만 가능) |
| 결재완료 | 결재가 승인되어 다음 단계로 | 없음 (되돌릴 수 없음) |
| 결재반려 | 결재자가 반려함             | 수정 · 삭제 · 재상신 |
| 상신취소 | 상신을 취소함               | 수정 · 삭제 · 재상신 |

Check Point
1. 결재중·결재완료 상태에서는 [저장], [삭제], [Submit] 버튼이 **하나도 보이지 않는다.**
   입력 항목도 모두 잠긴다. 버튼이 사라졌다면 먼저 진행상태를 확인한다.
2. 결재반려나 상신취소를 받으면 작성중과 똑같이 다시 수정하고 상신할 수 있다.
3. 결재중인 문서를 수정하려면 KNOX에서 상신을 취소한 뒤 수정한다.
4. KNOX 결재함에서 문서를 열면 CPMS 화면이 결재용 조회 화면으로 열린다. 이 화면에서는
   내용 확인만 가능하고 수정은 되지 않는다.


1.5 계약 일반

(1) 계약의뢰유형
계약의뢰서에서 선택하는 업체선정방식은 입찰 · 수의 · 변경 3가지이며, 선택에 따라
이후 진행 경로가 완전히 달라진다.

| 업체선정방식 | 결재완료 후 진행 경로 |
|---|---|
| 입찰 | 계약사전보고 → 입찰안내 → 현장설명회 → 질의응답 → 입찰 → 평가/업체선정 → 계약품의 |
| 수의 | 계약사전보고와 입찰 단계를 **거치지 않고** 곧바로 계약품의 |
| 변경 | 〃 |

Check Point
1. 계약사전보고 List에는 **업체선정방식이 '입찰'인 건만** 조회된다. 수의·변경으로 의뢰한
   건은 결재를 완료해도 계약사전보고 목록에 나타나지 않는다.
2. 같은 이유로 계약사전보고 List의 검색 조건에서 '계약형태'를 수의나 변경으로 선택하면
   조회 결과가 항상 0건이다. 계약형태 조건은 비워두고 조회한다.
3. 수의·변경은 계약의뢰 결재가 완료되면 곧바로 계약품의 대상이 된다.


(2) 계약담당자
역할의 종류와 부여 방법은 1.6 에 정리하였다. 여기서는 문서마다 "담당자"로 기록되는
사람이 누구인지만 정리한다.

| 문서 | 담당자로 기록되는 사람 |
|---|---|
| 계약의뢰서       | 계약의뢰서를 작성한 의뢰부서 담당자 |
| 계약사전보고     | 계약사전보고를 작성한 구매부서 담당자 (= 입찰담당자) |
| 현장설명서 ※미사용 | 작성자 / 검토자 / 참조(부서장) |
| 현장설명회 결과  | 현장설명회 결과를 작성한 담당자 |
| 평가             | 계약의뢰서에서 지정한 기술평가위원과 환경안전 평가위원 |
| 업체 측          | 업체정보에 입찰담당자로 등록된 협력사 담당자 |

Check Point
1. 매뉴얼에서 "입찰담당자"라고 부르는 사람은 **계약사전보고를 작성한 계약진행자 본인**이다.
   따로 지정하는 항목이 아니라, 계약사전보고를 등록한 사람이 그대로 입찰담당자가 된다.
2. 문서의 수정·삭제는 대부분 **등록한 본인만** 할 수 있다. 같은 부서 동료라도 다른 사람이
   등록한 문서는 조회만 가능하다.


(3) 계약업무 프로세스 전반

계약의뢰서의 진행상태는 다음 순서로 바뀐다. 괄호 안은 그 동작을 할 수 있는 역할이다.

    작성중 ──검토요청(의뢰자)──> 검토요청 ──의뢰접수(구매부서)──> 의뢰접수
        ──상신(의뢰자)──> 결재중 ──> 결재완료

    되돌리는 경우
      검토요청 상태에서  : [의뢰반려](구매부서) → 의뢰반려
                           [요청취소](의뢰자)   → 요청취소
      의뢰접수 상태에서  : [의뢰접수취소](구매부서) → 의뢰접수취소

각 단계에서 **다음 화면에 건이 나타나기 위한 조건**은 다음과 같다.
"목록에 안 보인다"는 문의는 대부분 여기에 해당한다.

| 다음 화면 | 나타나기 위한 조건 |
|---|---|
| 계약사전보고 List     | 계약의뢰 결재완료 + 업체선정방식이 '입찰' |
| 입찰안내서 List(업체) | 계약사전보고 결재완료 + 우리 업체로 입찰안내서가 발송됨 |
| 현장설명회 결과 List  | 계약사전보고 결재완료 |
| 질의응답 List         | 현장설명회 결과 결재완료 |
| 입찰 List             | 계약의뢰·계약사전보고·현장설명회 결과가 **모두** 결재완료 + 현장설명회 참여여부가 'Y' |
| 평가/업체선정 List    | 위 3건 모두 결재완료 + 입찰서제출 마감일시 경과 |
| 계약품의 List         | 계약의뢰 결재완료 + 계약의뢰서에 업체가 지정되어 있을 것 |

Check Point
1. 결재가 완료되지 않은(작성 중인) 건은 **작성자 본인에게만** 보인다. 다른 담당자에게
   보이게 하려면 반드시 결재를 완료해야 한다.
2. 계약품의는 계약의뢰서에 업체가 지정되어 있지 않으면 결재를 완료해도 목록에 나오지 않는다.
3. 각 단계는 앞 단계의 결재완료를 전제로 한다. 저장만 해두고 상신하지 않으면 다음 화면에
   건이 나타나지 않는다.


1.6 사용자 역할 및 권한

(1) 사용자 역할 구분
CPMS의 화면과 버튼은 로그인한 사용자의 역할에 따라 조회 범위와 사용 가능 여부가 달라진다.
계약관리에서 말하는 "역할"은 **부여받는 방법이 서로 다른 3가지**가 섞여 있다.
이를 구분하지 않으면 "역할을 받았는데 화면이 안 보인다"는 혼동이 생기므로 아래와 같이 나눈다.

[구분 1] 역할관리에서 부여하는 역할
         시스템관리자가 역할관리 메뉴에서 사용자에게 부여한다. 계약관리에서 사용하는 역할은
         다음 3가지다.

| 역할 | 매뉴얼에서 부르는 이름 | 하는 일 |
|---|---|---|
| 삼성전자 임직원 | — | 업체 사용자와 구분하는 기준 |
| 구매(계약)부서  | 계약진행자 | 계약의뢰 접수부터 계약품의까지 진행 |
| 계약 조회 전용  | 조회 역할 | 등록·수정 없이 조회만 |

  ※ 소속회사코드가 삼성전자인 사용자는 위 역할이 없어도 삼성전자 임직원으로 인식된다.
  ※ 위 역할이 하나도 없는 삼성전자 사용자는 자동으로 **의뢰부서(계약의뢰자)** 가 된다.
     계약의뢰자는 별도로 부여하는 역할이 아니다.

[구분 2] 업무그룹으로 지정하는 역할
         업무그룹관리 메뉴에서 지정한다. 계약관리에서 사용하는 것은 계약품의 관리자 1개다.

| 업무그룹 | 하는 일 |
|---|---|
| 계약품의 관리자 | 계약품의 건을 등록자가 아니어도 처리할 수 있다 |

[구분 3] 문서마다 지정하는 담당자
         역할관리에서 부여하는 것이 아니라, **해당 문서를 등록할 때 사람을 지정**한다.
         지정된 사람에게만 그 건에서 해당 버튼과 항목이 보인다.

| 담당자 | 어디서 지정하나 |
|---|---|
| 기술평가위원 (공사수행능력 / 공정관리 / 품질관리 / 안전환경) | 계약의뢰서 등록 시 항목별로 지정 |
| 환경안전 평가위원 | 시스템에 등록된 환경안전 평가 담당자 1명 (건별 지정 아님) |
| 현장설명서 검토자 · 참조(부서장) ※미사용 | 현장설명서 등록 시 검토항목별로 지정 |
| 업체 입찰담당자 | 업체정보에 등록 |

  ※ 현장설명서 검토항목은 시공 / 기성 / 보안 / 환경 / 법무 5가지이며, 항목마다 검토자와
     참조를 따로 지정한다. 다만 현장설명서 화면은 현행 메뉴에서 내려가 현재는 사용하지 않는다.

Check Point
1. 한 사용자가 여러 역할을 함께 가질 수 있으며, 화면마다 요구하는 역할이 다르다.
2. 삼성전자 임직원 역할도 없고 회사코드도 삼성전자가 아니면 업체 사용자로 취급된다.
3. **[구분 3]의 담당자는 역할관리에서 부여할 수 없다.** 해당 문서를 먼저 등록하고 그 안에서
   사람을 지정해야 생긴다. "역할을 줬는데 버튼이 안 보인다"의 가장 흔한 원인이다.
4. 환경안전 평가위원은 시스템에 등록된 담당자 1명뿐이다. 다른 사용자에게 역할을 부여해도
   환경안전 평가 점수는 보이지 않는다. 담당자를 바꾸려면 시스템 담당자에게 요청해야 한다.
5. 문서를 등록한 본인인지 여부가 버튼 활성화의 기준이 되는 경우가 많다. 역할이 맞는데도
   버튼이 안 보이면 그 문서를 내가 등록한 것이 맞는지 확인한다.


(2) 역할별 조회 범위

| 역할 | 조회할 수 있는 범위 |
|---|---|
| 의뢰부서(계약의뢰자) | 본인이 등록한 계약의뢰 건 |
| 구매(계약)부서       | 진행상태가 검토요청 이후인 계약의뢰 건 전체 |
| 조회 역할           | 구매(계약)부서와 동일. 단 등록·수정 불가 |
| 업체담당자          | 본인 업체가 대상업체로 등록되고 입찰안내서를 받은 건 |
| 각종 담당자         | 본인이 검토자·평가위원 등으로 지정된 건 |

Check Point
1. 위 범위 안에 들어와도 **결재가 완료되지 않은 건은 등록한 본인에게만** 보인다.
2. 목록에 건이 안 보일 때는 ① 내 역할이 맞는지 ② 앞 단계가 결재완료되었는지
   ③ 검색 조건(특히 기간)이 맞는지 순서로 확인한다.


1.7 자동 발송 메일 안내

CPMS는 업무 처리 단계마다 관련자에게 안내 메일을 자동으로 발송한다. "메일을 못 받았다"는
문의가 있을 때는 아래 표에서 해당 단계의 발송 시점과 수신자를 먼저 확인한다.

| 발송 시점 | 수신자 | 관련 절 |
|---|---|---|
| 계약의뢰자가 [검토요청] 처리 | 공통코드로 지정된 구매팀 인원 전원 | 2.2 |
| 계약진행자가 [의뢰접수] / [의뢰반려] / [의뢰접수취소] 처리 | 계약의뢰 등록자 | 3.1 (3) |
| 계약기간 만료 60일 전 (시스템이 자동 발송) | 계약의뢰 등록자 | — |
| 계약진행자가 계약서를 첨부하여 등록 | 계약의뢰 등록자 | 3.1 (4) |
| 계약진행자가 입찰안내서 [발송] | 대상업체 담당자 (업체별로 따로 발송하며, 참여여부를 이미 등록한 업체는 제외) | 3.2 (2), 3.3 (2) |
| 업체담당자가 참여여부를 저장 | 입찰담당자 | 8.1 (2) |
| 업체담당자가 질의를 상신 | 입찰담당자 | 3.5, 8.2 |
| 질의 답변의 결재가 완료 (자동) | 질의를 등록한 각 업체의 담당자 | 3.5 (2) |
| 업체담당자가 투찰 | 입찰담당자 | 8.3 (2) |
| 계약진행자가 [평가위원 지정] 화면에서 [통보] | 지정된 평가위원 전원 (평가항목별 최대 3명, 환경안전평가는 1명) | 3.7 (3) |
| 평가위원이 평가 점수를 등록 | 입찰담당자(수신) + 같은 항목의 다른 평가위원 중 본인 제외 최대 2명(참조) | 5.2, 6.2 |
| 계약진행자가 계약품의를 [전달] | 화면에서 지정한 수신 / 참조 / 숨은참조 대상자 | 3.8 (2) |
| 산출담당자가 진행상태를 '예정가검토'로 변경 | 예정가 산출을 의뢰한 담당자 | 7.2 (2) |
| 현장설명서 [검토요청] / 검토결과 저장  ※ 현행 미사용 | 검토담당자 및 입찰담당자(참조로 부서장 포함) | 4장 |

Check Point
1. 보낸사람이 처리자 본인이 아닌 경우가 있다. 투찰 알림, 질의 상신 알림, 참여여부 회신 알림,
   예정가 산출 결과 전달, 계약기간 만료 안내 이렇게 다섯 가지는 시스템 대표 주소(또는 안내
   전용 계정)로 발송되므로 메일의 보낸사람이 실제 처리한 담당자와 다르게 표시된다.
   나머지는 처리한 담당자 본인의 메일 주소로 발송된다.
2. 메일은 참고용 알림이다. 실제 처리 여부와 최신 상태는 반드시 CPMS 화면에서 다시 확인한다.
3. 표에 있는 단계라도 수신자로 지정될 대상(담당자·평가위원 등)이 시스템에 올바르게 등록되어
   있지 않으면 메일이 발송되지 않거나 다른 사람에게 갈 수 있다.
4. ※ 현행 미사용으로 표시한 항목은 현재 메뉴에서 내려간 화면이며 참고용으로만 남겨둔다.


# 2. 계약의뢰자

이 장은 **의뢰부서(운영부서)** 담당자를 위한 것이다.
구매(계약)부서 역할도 조회 역할도 없는 삼성전자 사용자는 자동으로 의뢰부서로 인식된다.

2.1 계약의뢰 경로
계약관리 > 계약의뢰 > 계약의뢰서 List

2.2 CPMS 업무 프로세스

(1) 계약업무개요
계약의뢰자는 공사 계약이 필요할 때 계약의뢰서를 작성하여 구매(계약)부서에 검토를 요청한다.
계약의뢰자가 직접 수행하는 구간은 다음 두 단계이며, 이후 단계는 계약진행자가 이어받는다.

  1) 계약의뢰서 작성 → [저장] → [검토요청]
  2) 구매부서가 [의뢰접수] 한 뒤 → 계약의뢰자가 [Submit] 으로 결재 상신 → 결재완료

Check Point
1. 검토요청 이후에는 계약의뢰서를 수정할 수 없다. 수정하려면 [요청취소] 후 수정한다.
2. [검토요청]을 누르면 예산 정보를 먼저 검증하며, 아래에 해당하면 안내 문구만 뜨고
   검토요청이 진행되지 않는다.
   - 예정가를 입력하지 않은 경우 (예산 확보 여부와 관계없이 항상 확인한다)
   - '예산 확보'를 선택했는데 예산 금액이 예정가보다 작은 경우
   - '예산 확보'를 선택했는데 예산 단위(화폐단위)를 선택하지 않은 경우
   '예산 미확보'를 선택하면 예산 금액 비교와 단위 조건은 확인하지 않는다.
3. 상신(Submit)은 구매부서가 의뢰접수(ACCEPT)를 처리한 뒤에야 활성화된다.
4. 결재가 완료되면 계약형태에 따라 다음 화면으로 넘어간다(1.5 (1) 참조).
5. 계약의뢰서 신규 작성은 의뢰부서 사용자만 가능하다. 구매(계약)부서나 조회 역할
   사용자에게는 [등록] 버튼이 보이지 않는다.
6. [요청취소]는 등록자 본인이면서 현재 자신의 역할이 의뢰부서일 때만 나타난다. 등록한 뒤에
   역할이 구매(계약)부서나 조회 역할로 바뀌면, 본인이 작성한 건이라도 [요청취소] 버튼이
   보이지 않는다.


(2) 계약의뢰서 List 조회
1. 조회할 조건을 입력을 입력한다.
2. [Search] 버튼을 클릭하여 계약의뢰 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [등록] 버튼을 클릭하여 계약의뢰서 팝업을 실행한다. (☞ (3) 계약의뢰서 등록 팝업 창이 나타남)
  * 상세 조회하고자 하는 항목 더블 클릭 (☞ (3) 계약의뢰서 등록 팝업 창이 나타남)
5. 계약품의가 완료된 의뢰에 첨부된 계약서가 있는 경우 첨부파일 팝업을 실행해 계약서를 다운받을 수 있다.

Check Point
1. 계약의뢰 List 항목은 등록자만 조회 가능하다.
2. 계약의뢰에 관한 전체 진행 사항을 확인할 수 있다.
3. [등록] 버튼은 운영부서 사용자인 경우에만 활성화 된다.
4. 계약부서인 경우 진행상태가 검토요청 상태 이후에만 계약의뢰 List 조회/상세조회 가능하다.
5. 조회 역할이 부여된 사용자는 구매(계약)부서와 동일하게 검토요청 이후 상태의 의뢰를 조회할 수 있다.
6. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel 저장할 수 있다.


(3) 계약의뢰서 등록
1. 계약의뢰서 List에서 [등록] 버튼을 클릭하여 작성 화면을 연다.
2. 공사를 검색하여 프로젝트·공사 기본정보를 불러온다.
3. 계약형태(입찰 / 수의 / 변경)를 선택한다. 계약형태에 따라 이후 입력할 필수항목이 달라진다.
4. 예산 확보 여부를 선택하고 비용정보를 입력한다. 공사 유형이 투자이면 Cost정보를 추가하여
   선택하고, 경비이면 예산 금액을 직접 입력한다.
5. 계약형태가 입찰이면 평가유형(기술평가 여부)과 환경안전평가 여부를 선택한다.
6. 첨부서류를 등록한다.
7. [저장]으로 임시 저장하거나, 입력을 마쳤으면 [검토요청]을 클릭하여 구매부서에 검토를 요청한다.

Check Point
1. 계약의뢰서는 운영부서 사용자만 신규작성이 가능하다.
2. 작성된 계약의뢰서 내용의 수정은 등록자만 가능하다.
3. 업체선정방식에 따라 변경되는 필수입력항목(*)을 입력해야 저장이 가능하다.
4. 검토요청 후 계약의뢰 정보를 수정하려는 경우 요청취소 후 수정이 가능하다.
5. 공사 유형 선택에 따라 Cost정보 선택 또는 예산을 직접 입력한다.
6. 투자인 경우 Cost정보 추가는 기본정보 저장 이후에 가능하다.
7. 한번 사용한 Cost정보는 재사용 할 수 없다. 단, 그 Cost정보를 사용했던 계약의뢰서의 입찰이
   유찰된 경우에는 다시 선택할 수 있다.
8. 의뢰접수가 정상적으로 처리되면 Submit 버튼이 활성화되며 결재처리가 가능하다.
9. 결재가 승인되면 계약의뢰서는 완료 상태로 변경된다. (계약의뢰서 요청완료)
10. 기술평가 여부와 환경안전평가 여부는 계약형태가 입찰인 경우에만 나타나는 필수 선택 항목이다.
    기술평가 여부에서 '실시'를 선택한 경우에만 기술인력·공사관리·품질관리·안전관리 4개 분야의
    평가위원 지정이 필수가 된다.
11. 입찰까지 진행했다가 유찰된 건은 계약의뢰서 상세 화면에 [재의뢰] 버튼이 나타난다. 클릭하면
    기존 내용과 첨부서류를 복사한 새 계약의뢰서가 작성중 상태로 만들어진다. 예정가는 그대로
    넘어오지만 예산과 예산 단위는 초기화되므로 다시 입력해야 한다. 이미 재의뢰를 한 건에는
    이 버튼이 다시 나타나지 않는다.


# 3. 계약진행자

3.1 계약의뢰
계약관리 > 계약의뢰 > 계약의뢰서 List

(1) 계약진행자의 처리 구간
계약의뢰서는 의뢰부서(계약의뢰자)가 작성한다. 계약진행자는 올라온 검토요청을 확인하여
접수하거나 반려하며, 계약의뢰서를 직접 작성하지는 않는다.

  1) 계약의뢰자가 [검토요청]                              → 상태 : 검토요청
  2) 계약진행자가 [의뢰접수]                              → 상태 : 의뢰접수
     또는          [의뢰반려]                              → 상태 : 의뢰반려
  3) 의뢰접수된 건은 계약의뢰자가 [Submit] 으로 결재 상신  → 상태 : 진행중 → 완료
  4) 접수를 잘못하였으면 계약진행자가 [의뢰접수취소]       → 상태 : 의뢰접수취소

Check Point
1. 계약진행자에게는 [등록] 버튼이 나타나지 않는다. 계약의뢰서 신규 작성은 의뢰부서 사용자만 가능하다.
2. 결재 상신([Submit])은 계약의뢰자가 수행한다. 계약진행자가 [의뢰접수]를 처리해야만
   계약의뢰자 화면에 [Submit] 버튼이 나타나므로, 접수하지 않으면 결재가 진행되지 않는다.
3. 검토요청 알림 메일은 공통코드 'BID_MAIL'에 지정된 구매팀 인원에게만 발송된다.
   이 코드에 등록되어 있지 않으면 검토요청이 올라와도 메일을 받지 못하므로 목록을 직접 조회해야 한다.


(2) 계약의뢰 List 조회
1. 조회 조건을 입력한다. 프로젝트, 공사명, 계약형태, 계약진척현황, 등록자, 등록일,
   대공종, 공사코드, 검토요청일, 관리번호로 검색할 수 있다.
2. [Search] 버튼을 클릭하여 계약의뢰 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. 처리하고자 하는 항목을 더블 클릭한다. (☞ (3) 계약의뢰서 상세 화면이 나타남)
5. '계약진척현황' 값을 클릭하면 해당 계약의뢰의 진행이력 팝업이 나타난다.
6. '첨부' 항목을 클릭하면 계약서 등록 창이 나타난다. (☞ (4) 계약서 등록)
7. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

Check Point
1. 계약진행자에게는 **검토요청 이후 상태의 건만** 조회된다. 계약의뢰자가 작성만 하고
   아직 검토요청하지 않은 건(작성중)은 목록에 나타나지 않는다.
2. 정확히는 다음 네 가지 상태만 조회된다.
   검토요청 / 의뢰접수 / 진행중 / 완료
   요청취소 · 의뢰반려 · 의뢰접수취소 · 결재반려 · 상신취소 상태의 건은 **목록에서 사라진다.**
   따라서 반려 처리한 건은 계약의뢰자가 수정하여 다시 검토요청해야 목록에 다시 나타난다.
3. 조회 기간의 기본값은 등록일 기준 최근 2개월이다.
4. '계약진척현황' 컬럼은 계약의뢰 자체의 상태가 아니라 **가장 앞서 진행된 단계의 상태**를 보여준다.
   계약품의 > 입찰 > 현장설명회 결과 > 현장설명회 > 입찰안내 > 계약사전보고 > 계약의뢰 순으로
   우선하므로, 계약사전보고가 시작된 건은 계약의뢰 상태 대신 사전보고 상태가 표시된다.
5. 계약품의가 결재완료된 건에만 '첨부' 또는 '미첨부' 표시가 나타난다. 계약품의 이전 단계에서는
   해당 칸이 비어 있으며 계약서를 등록할 수 없다.
6. 조회 역할(1.6 (1) 참조)이 부여된 사용자는 계약진행자와 같은 범위를 조회할 수 있으나,
   상세 화면에서 [의뢰접수] · [의뢰반려] · [의뢰접수취소] 버튼은 나타나지 않는다.


(3) 의뢰접수 / 의뢰반려 / 의뢰접수취소
1. List에서 처리할 항목을 더블 클릭하여 계약의뢰서 상세 화면을 연다.
2. 의뢰 내용, 예산과 예정가, Cost 정보, 첨부서류를 확인한다.
3. 접수하려면 [의뢰접수] 버튼을 클릭한다. 접수 Comment를 입력하고 [의뢰접수] 버튼을 클릭한다.
4. 반려하려면 [의뢰반려] 버튼을 클릭한다. 재작성 요청사유를 입력하고 [의뢰반려] 버튼을 클릭한다.
5. 접수를 취소하려면 [의뢰접수취소] 버튼을 클릭한다. 의뢰접수 취소사유를 입력하고
   [의뢰접수취소] 버튼을 클릭한다.

Check Point
1. 버튼은 계약의뢰 상태에 따라 다음과 같이 나타난다.

   | 계약의뢰 상태 | 계약진행자에게 나타나는 버튼   |
   |---------------|--------------------------------|
   | 검토요청      | [의뢰접수] [의뢰반려]          |
   | 의뢰접수      | [의뢰접수취소]                 |
   | 그 외         | 없음                           |

2. 세 가지 처리 모두 **사유(Comment) 입력이 필수**이며, 비워 두면 다음으로 진행되지 않는다.
3. 사유에 허용되지 않는 특수문자가 포함되면 안내 후 진행되지 않는다.
4. 처리가 완료되면 계약의뢰 등록자에게 메일이 자동 발송된다.
   제목은 `[(대공종)공사명] 의뢰접수` / `의뢰반려` / `의뢰접수취소` 형식이며 상세 화면 링크가 포함된다.
5. [의뢰반려] 를 처리하면 상세 창이 자동으로 닫힌다.
6. [의뢰접수취소] 를 처리하면 계약의뢰자가 다시 수정하고 검토요청할 수 있는 상태로 돌아간다.
7. 계약진행자는 계약의뢰서의 내용을 수정하거나 삭제할 수 없다. 내용에 문제가 있으면
   반려하여 계약의뢰자가 수정하도록 한다.
8. 의뢰반려 상태로 2주(14일)가 지나도록 계약의뢰자가 수정·재검토요청을 하지 않으면,
   시스템이 해당 계약의뢰서와 연결된 비용정보를 자동으로 삭제 처리한다. 삭제된 건은
   목록에서 사라지고 되돌릴 수 없으므로, 반려할 때 재작성 기한을 함께 안내하는 것이 좋다.


(4) 계약서 등록
1. 계약의뢰 List에서 계약품의가 완료된 건의 '첨부' 항목을 클릭한다.
2. 파일찾기 버튼을 클릭하여 체결된 계약서를 첨부한다.
3. [Save] 버튼을 클릭한다. 계약일자 확인 메시지와 저장 확인 메시지에 모두 [확인]을 눌러야 저장된다.

Check Point
1. 이 창은 역할에 따라 다르게 열린다. 계약진행자에게는 '계약서 등록' 창으로 열려 첨부와 저장이
   가능하고, 계약의뢰자에게는 '계약서 보기' 창으로 열려 조회만 가능하다.
2. 계약의뢰자는 **본인이 등록한 건이면서 계약서가 이미 첨부된 경우**에만 창을 열 수 있다.
   계약진행자는 첨부 전('미첨부') 상태에서도 창을 열어 등록할 수 있다.
3. 저장 시 나타나는 확인 메시지에는 계약일자가 함께 표시된다. 입찰·수의 계약은 계약기간의
   시작일이, 변경계약은 변경 계약기간의 시작일이 표시되므로 확인 후 저장한다.
4. 계약서가 저장되면 계약의뢰 등록자에게 등록 완료 메일이 발송되며, List의 해당 항목이
   '미첨부'에서 '첨부'로 바뀐다.
5. 계약서가 첨부되지 않은 상태에서는 계약의뢰서 상세 화면에 [계약기간변경] 버튼이 나타나
   계약진행자가 계약기간을 수정할 수 있다.


3.2 계약사전보고

(1) 계약사전보고 List 조회
1. 조회할 조회 조건을 입력한다.
2. [Search] 버튼을 클릭하여 계약사전보고 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. 상태가 미작성인 항목을 더블 클릭해 계약사전보고를 등록한다. (☞ (2) 계약사전보고 등록 창이 나타남)
5. 상세 조회하고자 하는 항목을 더블 클릭한다.

Check Point
1. 계약의뢰의 업체선정방식이 '입찰'이고 계약의뢰 결재가 완료된 건에 한하여 List에 조회된다.
   업체선정방식이 수의·변경인 건은 계약의뢰 결재가 완료되어도 이 List에 조회되지 않으며,
   계약품의 List로 바로 넘어간다(3.7 참조). 조회 조건의 '계약형태'에서 수의 또는 변경을
   선택하면 조회 결과가 없다.
2. 계약사전보고 상세 화면은 삼성전자 소속이면서 구매부서 권한을 함께 보유한 사용자만 조회할 수 있으며,
   그 외 사용자는 권한 없음 화면이 나타난다.
3. 결재 완료 이전(작성중, 결재중, 상신취소, 반려)의 계약사전보고 등록 건은 등록자 본인만 조회 가능하다.
   (미작성은 조회 권한이 있는 사용자가 모두 조회 가능)
4. 미작성 → 결재중 → 결재완료(참여등록 마감 전) → 결재완료(참여등록 마감 후) 순으로 정렬되어 조회된다.
5. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(2) 계약사전보고 등록 (입찰)
1. 입찰수행 정보(참여등록 마감일시, 현장설명회 일시, 질의응답 마감일시, 입찰마감 일시, 평가마감 일시,
   낙찰자 결정 일시)를 입력한다.
2. 입찰 대상업체는 [추가] 버튼을 클릭하여 선택한다. (☞ (4) 대상업체 조회 창이 나타남)
3. 대상업체 [삭제] 버튼을 클릭하여 입찰 대상업체에서 제외할 수 있다.
4. 입찰수행 정보, 대상업체, 파일 첨부 후 [저장] 버튼을 클릭하여 저장한다.
5. [삭제] 버튼을 클릭하여 저장된 계약사전보고 정보를 삭제할 수 있다.
6. [Submit] 버튼을 클릭하여 결재를 상신한다.
7. 결재 완료 후 [안내서 발송] 버튼을 클릭하여 대상업체에 입찰안내서를 발송한다.
8. [발송이력] 버튼을 클릭하여 입찰안내서 발송 이력을 확인할 수 있다.

Check Point
1. 관리번호는 최초 저장 시에 생성된다.
2. 입찰수행 정보의 각 마감일을 입력할 때는 다음과 같이 날짜 선후 조건을 만족해야 한다.
(현재일 < 참여등록 마감일시 < 현장설명회 일시 < 질의응답 마감 일시 < 입찰마감 일시 < 평가마감 일시 < 낙찰자 결정 일시)
   ※ '낙찰자 결정 일시 < 공사시작일' 조건은 2023.05.12 자로 해제되어 현재는 검증하지 않는다.
     낙찰자 결정 일시를 공사시작일 이후로 입력해도 저장된다.
3. [저장] 버튼은 신규 작성이거나, 진행상태가 작성중·상신취소·결재반려이면서 등록자 본인인 경우에만 활성화된다.
4. [삭제], [Submit] 버튼은 진행상태가 작성중이면서 등록자 본인인 경우에만 활성화된다.
5. 대상업체 [추가], [삭제] 버튼은 [저장] 버튼이 활성화된 상태에서만 사용할 수 있다.
6. [안내서 발송] 버튼은 결재완료 상태이고 참여등록 마감일시가 경과하지 않았으며 등록자 본인인 경우에만 활성화된다.
7. [발송이력] 버튼은 결재완료 상태이고 참여등록 마감일시가 경과하지 않은 경우에 활성화된다.
8. 결재를 상신하면 입력 항목 전체가 비활성화되어 계약사전보고 정보를 수정할 수 없다.
   (진행상태가 작성중·상신취소·결재반려인 경우에만 입력이 가능하며, 상신취소되거나 반려되면
    다시 수정할 수 있다. 첨부파일 추가·삭제도 동일한 조건으로 제한된다.)
9. 결재가 승인되면 계약사전보고는 완료 상태로 변경되며, 입찰안내 List에서 조회가 가능해진다.


(3) 계약사전보고 등록 (수의/변경)

※ 본 화면은 현행 CPMS 프로세스에서 사용되지 않는다.
  업체선정방식이 수의 또는 변경인 계약의뢰 건은 계약사전보고 단계를 거치지 않고,
  계약의뢰 결재가 완료되면 계약품의 List로 바로 넘어간다(3.7 참조).
  화면 자체는 남아 있으나 메뉴에서 들어갈 경로가 없으므로, 아래 내용은 참고용으로만 둔다.

[참고] 화면이 호출될 경우의 동작
1. 계약사전보고 정보를 입력 후 [저장] 버튼을 클릭하여 저장한다.
2. [삭제] 버튼을 클릭하여 저장된 계약사전보고 정보를 삭제할 수 있다.
3. [Submit] 버튼을 클릭하여 결재를 상신한다.

Check Point
1. 계약의뢰서의 업체선정방식이 수의 또는 변경인 경우 입찰 대상업체 및 입찰안내서 발송 기능이 없는 화면이 나타난다.
2. [저장], [삭제], [Submit] 버튼의 활성화 조건은 입찰의 경우와 동일하다.


(4) 대상업체 조회
1. 검색할 입찰 대상 업체명을 입력한다.
2. [Search] 버튼을 클릭하여 검색할 입찰 대상 업체를 검색한다.
3. 입찰 대상 업체를 선택하고 [선택] 버튼을 클릭하면 추가된다.

Check Point
1. 입찰 대상업체로 추가하려면 거래가능, 입찰가능, 입찰담당자 지정이 모두 ○ 표시되어 있어야 한다.
2. 계약의뢰서에 선택된 업체카테고리(소)에 해당하고 결재가 완료된 사용중인 업체만 검색된다.
3. 최초 조회 시에는 업체 Pool을 기준으로 조회되고, 저장 이후에는 등록된 대상업체를 기준으로 조회된다.


3.3 입찰안내

(1) 입찰안내서 List 조회
1. 조회할 조건을 입력을 입력한다.
2. [Search] 버튼을 클릭하여 입찰안내서 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [등록] 버튼을 클릭하면 입찰안내서 등록 팝업이 열린다.
   ※ 이 버튼은 계약사전보고 등록과 무관하다. 계약사전보고는 3.2 (1) 계약사전보고 List에서
      행을 더블클릭해 등록/상세로 진입한다(그 화면에는 [등록] 버튼이 없음).
   ※ 확인 필요 — 이 버튼이 현재 운영에서 실제로 사용되는지 확인이 필요하다.
5. 상세 조회하고자 하는 항목을 더블 클릭한다. (☞ (2) 입찰안내서 발송 창이 나타남)

Check Point
1. 계약의뢰의 업체선정방식이 입찰인 건 중 계약의뢰와 계약사전보고가 모두 결재완료된 건만 조회된다.
2. [등록] 버튼은 삼성전자 사용자인 경우에만 활성화되며, 업체담당자에게는 나타나지 않는다.
3. 업체담당자는 본인 업체가 대상업체로 등록되고 입찰안내서가 발송된 건만 조회할 수 있다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(2) 입찰안내서 발송
1. 입찰안내서 상세내용을 조회한다.
2. [안내서 발송] 버튼을 클릭하여 입찰 대상업체에 입찰안내서를 발송한다.
3. [발송이력] 버튼을 클릭하여 입찰안내서 발송 이력을 확인할 수 있다.

Check Point
1. 입찰안내서 발송은 계약사전보고 상세 화면의 대상업체 영역에서 수행한다.
2. 안내서 발송시 최종 발송일시 및 업체 참여여부 등록일을 조회할 수 있다.
3. 입찰안내서를 발송해야 대상업체 담당자가 입찰안내서 List에서 조회가 가능하다.
4. 참여등록 마감일시가 경과하면 [안내서 발송], [발송이력] 버튼이 나타나지 않는다.


3.4 현장설명회 관리

■ (1) 현장설명서 List 조회 · (2) 현장설명서 등록은 현행 CPMS 메뉴에서 사용하지 않는다.
  현재 메뉴에는 '현장설명회 결과 List'만 노출되어 있으며, 현장설명서 화면은 메뉴에서
  내려갔다(화면 자체는 남아 있어 주소로 직접 열면 표시된다).
  현장설명서를 등록하지 않아도 이후 단계는 정상 진행된다. 현장설명회 결과 등록 화면은
  현장설명서가 아니라 **계약사전보고**에서 일정 초기값을 가져오며, 질의응답·입찰·평가·
  계약품의 어느 단계도 현장설명서를 필요로 하지 않는다.
  아래 (1)(2)와 「4. 현장설명서 검토담당자」는 **참고용**으로만 남긴다.
  → 실제 업무는 (3) 현장설명회 결과 List 조회부터 시작한다.


(1) 현장설명서 List 조회  ※ 현행 미사용 — 참고용
1. 조회할 조회 조건을 입력한다.
2. [Search] 버튼을 클릭하여 현장설명서 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. 상태가 미작성인 항목을 더블 클릭해 현장설명서를 등록한다. (☞ (2) 현장설명서 등록 창이 나타남)
5. 상세 조회하고자 하는 입찰공사를 더블 클릭한다.

Check Point
1. 현장설명서 검토현황은 각 담당자의 검토 결과 상태가 출력된다.
2. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.
3. 계약의뢰와 계약사전보고가 모두 결재완료된 입찰(BID) 건만 조회된다.
4. 결재 완료 이전(작성중·결재중·상신취소·반려)의 현장설명서는 등록자 본인, 검토자,
   검토 부서장에게만 보인다. 미작성(READY) 건은 제한 없이 모두에게 보인다.
5. 화면 자체에는 역할 게이트가 없다. 메뉴 URL 로 진입하면 누구나 열 수 있고,
   보이고 안 보이고는 아래 행 단위 조회권한으로만 결정된다.


(2) 현장설명서 등록  ※ 현행 미사용 — 참고용
1. 현장설명서 정보를 입력한다.
2. 검토자 및 검토자의 참조(부서장)인을 검색하여 입력한다.
3. 현장설명서 정보 입력 후 [저장] 버튼을 클릭하여 현장설명서 정보를 저장한다.
4. [삭제] 버튼을 클릭하여 저장된 현장설명서 정보를 삭제한다.
5. 현장설명서 [등록] 버튼을 클릭하여 검토해야 할 현장설명서를 첨부한다.
6. 검토항목을 선택 후 [검토요청] 버튼을 클릭하여 선택된 검토자/참조(부서장)에게 검토 요청 메일을 발송한다.
7. [완료] 버튼을 클릭하여 현장설명서 등록을 완료한다.

Check Point
1. 모든 필수입력항목(*)을 입력해야 저장이 가능하다.
2. [저장] 버튼은 미작성 상태이거나, 작성중 상태이면서 등록자 본인인 경우에 활성화된다.
3. [완료], [삭제] 버튼은 작성중 상태이면서 등록자 본인인 경우에만 활성화된다.
4. 현장설명서 [등록], [검토요청] 버튼은 최초 저장 이후 등록자 본인에게만 나타난다.
5. 같은 화면에 [현장설명서 보기], [결과저장] 버튼이 있으나 이는 **검토담당자 전용**이며
   계약진행자에게는 나타나지 않는다. → 「4. 현장설명서 검토담당자」 참조.
6. 회신요청일은 현재일 이후, 현장설명회 이전 일자만 입력 가능하다.
7. 완료 후에는 현장설명서 정보 수정이 불가능하며 등록/검토요청/결과저장 버튼이 모두 사라진다.
8. 완료 후에는 현장설명회 결과 List에서 결과 등록이 가능하다.
   ※ 현재는 현장설명서를 등록하지 않아도 현장설명회 결과를 등록할 수 있다.


(3) 현장설명회 결과 List 조회

화면 구성
검색 조건은 6개다. 입찰공사명 / 현장설명회 일시(기간) / 입찰예정일(기간) /
공사기간(기간) / 등록자 / 등록일(기간).
  ※ 진행상태(결재상태) 검색 조건은 없다. 상태로 걸러 보려면 그리드 정렬을 이용해야 한다.
  ※ 화면 버전에 따라 관리번호 검색 조건이 추가로 있을 수 있다.
목록 항목은 관리번호 / 공사명 / 현장설명회 일시 / 입찰마감일 / 공사기간 /
현장설명회 장소 / 등록자 / 등록일 / 진행상태 순이다.
버튼은 [Search] [Reset] [등록] [Excel 저장] 4개다.

절차
1. 조회할 조회 조건을 입력한다.
2. [Search] 버튼을 클릭하여 현장설명회 결과 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
   (확인 창이 뜨며, 확인 시 조건 초기화와 함께 그리드 데이터도 비워진다)
4. [등록] 버튼을 클릭하여 현장설명회 결과를 등록한다. (☞ (4) 현장설명회 결과 등록 창이 나타남)
5. 목록의 행을 더블 클릭하여 조회 또는 결과를 등록한다. 미작성 행을 더블 클릭하면
   신규 등록, 이미 등록된 행을 더블 클릭하면 해당 건의 상세로 열린다.
6. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

Check Point
1. 계약의뢰의 업체선정방식이 입찰(BID)이고, 계약사전보고가 결재완료된 건만 조회된다.
   수의·변경 건은 이 목록에 나타나지 않는다.
2. 현장설명서가 등록된 건은 그 현장설명서까지 결재완료되어야 조회된다.
   현장설명서를 아예 등록하지 않은 건은 이 조건과 무관하게 조회된다(외부조인).
3. 결재 완료 이전(작성중·결재중·상신취소·반려)의 건은 등록자 본인에게만 보인다.
   미작성(READY) 건과 결재완료 건은 모든 사용자에게 보인다.
4. 목록은 미작성 건이 위, 등록된 건이 아래로 정렬되며 각 그룹 안에서는
   관리번호 내림차순이다. 즉 처리해야 할 건이 항상 상단에 모인다.
5. 미작성 행의 관리번호·현장설명회 일시·장소·입찰마감일은 계약사전보고에 입력된 값이
   그대로 표시된다. 결과를 등록하면 현장설명회 결과에 입력한 값으로 대체된다.
6. [등록] 버튼에는 역할·권한 조건이 걸려 있지 않다. 화면에 들어온 사용자 누구에게나
   보인다.
7. 등록일 검색은 미작성 건을 걸러내지 않는다. 등록일 범위를 지정해도 아직 등록되지
   않은 건은 항상 함께 조회된다.


(4) 현장설명회 결과 등록
1. 변경된 입찰수행 정보를 입력한다.
2. 현장설명회에 참여한 업체를 선택하고 현장설명회 참가자에 실제 참가한 사람의 이름을 입력한다.
3. [저장] 버튼을 클릭하여 현장설명회 결과 정보를 저장한다.
4. [삭제] 버튼을 클릭하여 저장된 현장설명회 결과 정보를 삭제한다.
5. [Submit] 버튼을 클릭하여 저장된 현장설명회 결과 정보를 결재 상신한다.

Check Point
1. 필수 입력항목을 채워야 저장·상신이 가능하다. 실제로 검사하는 항목은 현장설명회 일시,
   현장설명회 장소, 질의응답 마감 일시, 입찰서제출 마감 일시, 평가마감 일시, 낙찰자결정 일시
   6개이며, 결과요약은 필수가 아니다(특수문자 검사만 한다).
   참여여부를 'Y'로 체크한 업체는 현장설명회 참가자 이름이 반드시 입력되어 있어야 한다.
   단 이 참가자명 검사는 [저장]에서만 수행되고 [Submit]에서는 수행되지 않는다.
2. 계약사전보고에 입력했던 입찰 수행 정보가 초기값으로 표시되며 수정할 수 있다. 날짜의 선후
   관계는 다음 조건을 만족해야 한다.
(참여등록 마감일시 < 현장설명회 일시 ≤ 현재일 < 질의응답 마감 일시 < 입찰서제출 마감 일시 < 평가마감 일시 < 낙찰자 결정 일시)
   ※ 계약사전보고 등록(3.2)과 방향이 다르다. 사전보고에서는 현장설명회 일시가 **미래**여야
     하지만, 결과 등록에서는 이미 열린 설명회의 결과를 적는 화면이므로 현장설명회 일시가
     **현재 시각 이전**이어야 한다. 아직 열리지 않은 날짜로 두면 저장되지 않는다.
   ※ '참여등록 마감일시 > 현재일' 조건은 이 화면에 없다.
   ※ '낙찰자 결정 일시 < 공사시작일' 조건은 2023.05.12 자로 해제되어 현재는 검증하지 않는다.
     공사시작일은 계약의뢰서 값이 그대로 표시되며 이 화면에서 수정할 수 없다.
3. 현장설명회 참여업체 목록에는 계약사전보고에서 입찰안내 대상으로 등록한 **업체 전체**가
   표시된다. 입찰 참여를 회신하지 않았거나 '불참'으로 회신한 업체도 함께 나오므로,
   실제로 현장설명회에 참석한 업체를 참여여부 체크박스로 직접 지정해야 한다.
4. 하나의 계약의뢰에 대해 현장설명회 결과는 1건만 등록할 수 있다. 다른 사용자가 먼저 등록한
   경우 "이미 등록된 데이터가 있습니다" 메시지가 뜨고 창이 닫히며 저장되지 않는다.
   먼저 등록된 건을 삭제하면 다시 등록할 수 있다.
5. 현장설명회 결과가 결재완료되어야 질의응답 List와 입찰 List에 해당 건이 조회된다.
   질의와 답변 양쪽 모두, 입찰 목록과 상세 양쪽 모두 같은 조건이다.
6. 현장설명회 참여여부를 '참여'로 등록한 업체만 투찰할 수 있다. 참여로 표시하지 않은 업체는
   입찰 List에 해당 건 자체가 나타나지 않는다.


3.5 질의응답

(1) 질의응답 List 조회
1. 조회할 조회 조건을 입력한다.
2. [Search] 버튼을 클릭하여 질의응답 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [답변 등록] 버튼을 클릭하여 업체가 질의한 건들에 대한 답변을 등록한다. (☞ (2) 답변 등록 창이 나타남)
5. 상세 조회하고자 하는 질의 또는 답변을 더블 클릭한다.

Check Point
1. 삼성전자 사용자에게는 [답변 등록] 버튼이, 업체담당자에게는 [질의등록] 버튼이 나타난다.
2. 현장설명회 결과가 결재완료된 건에 대해서만 질의 및 답변이 조회된다.
3. 완료 이전의 답변은 등록자 본인만 조회 가능하며, 업체가 등록한 질의는 질의 등록 완료된 건만 조회 가능하다.
   즉, 임시 저장 상태의 업체 질의 등록 건은 목록에 조회되지 않는다.
4. 답변의 업체명은 '삼성전자'로 표시된다.
5. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(2) 답변 등록
1. 답변 등록할 입찰공사 명을 검색하여 입력한다.
2. 파일찾기 버튼을 클릭하여 답변 파일을 첨부한다.
3. [저장] 버튼을 클릭하여 답변 정보를 저장한다.
4. [삭제] 버튼을 클릭하여 저장된 답변 정보를 삭제한다.
5. [Submit] 버튼을 클릭하여 저장된 답변 정보를 결재 상신한다.

Check Point
1. 모든 필수 입력항목(*)을 입력해야 저장이 가능하다.
2. 답변 기 등록된 입찰공사는 선택할 수 없으나, 결재상태가 상신취소나 반려인 건에 대해서는 선택하여 재 등록할 수 있다.
3. 현재 날짜가 현장설명회 일시 이후, 입찰서제출 마감 일시 이전인 입찰공사만 답변 등록할 수 있다.
4. 최초 저장 이후에 [삭제], [Submit] 버튼이 나타난다.
5. 답변 등록이 완료되면 질의를 등록한 업체담당자에게 메일이 발송된다.


3.6 입찰등록

(1) 입찰 List 조회
1. 등록자 항목에 등록자(투찰자) 명을 검색하여 입력한다.
2. [Search] 버튼을 클릭하여 입찰 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.

Check Point
1. 입찰 List 조회 화면은 업체의 투찰 현황에 대해서 확인하는 화면으로서 다른 화면과 달리 상세 조회를 할 수 없다.
2. 업체의 투찰 여부를 상태 칼럼(임시저장/투찰)을 통해 확인할 수 있다.
3. 삼성전자 사용자 중 구매부서 권한이 없는 사용자(의뢰팀 등)에게는 List가 조회되지 않는다.
4. 구매부서 사용자는 전체 건을, 업체담당자는 본인이 입찰담당자로 지정된 건만 조회할 수 있다.
5. 입찰중 상태의 투찰 상세는 조회할 수 없으며, 입찰중을 제외한 상태에서는 입찰담당자 본인만 상세 조회가 가능하다.
6. 계약의뢰·계약사전보고·현장설명회 결과가 모두 결재완료되고, 현장설명회에 참여한 업체만 List에 표시된다.
7. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


3.7 평가/업체선정

(1) 평가/업체선정 List 조회
1. [Search] 버튼을 클릭하여 평가/낙찰 List를 조회한다.
2. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
3. 상세 조회하고자 하는 평가건을 더블 클릭하여 조회하거나 평가등록 한다. (☞ (2) 평가 등록 창이 나타남)

Check Point
1. 입찰담당자만 평가 등록할 수 있고, 그 외 사용자는 조회만 가능하다.
2. 평가등록과 업체선정은 평가위원이 모두 평가완료하고 평가마감 일시가 지나야 할 수 있다.
3. 업체선정을 수행한 경우 입찰진행상태가 "낙찰완료"로 변경된다.
4. 입찰한 모든 업체가 입찰담당자의 예상금액보다 높은 입찰금액으로 투찰한 경우 "우선협상대상 선정실패" 상태로 변경된다.
5. List 화면에는 별도의 등록 버튼이 없으며, 평가 건을 더블 클릭하여 평가 등록 화면으로 진입한다.
6. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.
7. 투찰(입찰서류 제출) 마감 일시가 지나야 목록에 나타난다. 계약사전보고와 현장설명회 결과까지
   모두 결재완료되어 있어도 투찰 마감 전이면 조회되지 않는다.
8. 본인이 작성한 건이거나 본인이 평가위원으로 지정된 건이 아니라면, 결재가 완료되기 전까지는
   목록에 나타나지 않는다.


(2) 평가 등록
1. [평가위원 지정] 버튼을 클릭하여 해당 공사에 대한 기술평가 요청을 한다. (☞ (3) 평가위원 지정 창이 나타남)
2. [저장] 버튼을 클릭하여 입력 사항을 저장할 수 있다.
3. [삭제] 버튼을 클릭하여 저장된 평가 정보를 삭제한다.
4. 평가마감 일시가 지나면 [결과조회] 버튼을 클릭하여 평가결과를 확인할 수 있다. (☞ (4) 결과 조회 창이 나타남)

Check Point
1. 입찰담당자만 평가 등록할 수 있다.
2. 모든 필수 입력항목(*)을 입력해야 저장이 가능하다.
3. [평가위원 지정] 버튼은 계약의뢰서에서 기술평가 또는 환경안전평가 대상으로 선택된 건에 대해
   입찰담당자로 로그인한 경우에 나타난다.
4. [저장] 버튼은 진행상태가 미작성 또는 작성중이고, 입찰담당자 본인이며, 평가마감 일시가 경과하지 않은 경우에 활성화된다.
5. [삭제] 버튼은 저장 후 평가마감 일시 이전까지만 활성화된다.
6. [결과조회] 버튼은 입찰담당자 본인이면서 평가마감 일시가 경과한 경우에 활성화된다.
7. 업체명은 낙찰업체가 확정되기 전까지 AA, BB, CC …와 같이 익명으로 표시된다.
8. 이 화면은 계약진행자(입찰담당자)와 평가위원이 함께 사용하지만 보이는 것이 다르다.
   - 계약진행자 : 평가가 완료된 항목에 한하여 점수를 조회할 수 있다. 평가 입력은 불가하다.
   - 기술평가위원 : 본인이 담당하는 평가항목에만 점수 조회·평가 등록 창 아이콘이 나타난다.
     → 「5. 기술평가위원」 참조.
   - 환경안전 평가위원 : 환경안전 항목에만 아이콘이 나타난다. → 「6. 환경안전 평가위원」 참조.
9. 4개 기술평가 항목의 점수를 모두 조회할 수 있는 경우에만 소계가 표시된다.
10. 환경안전평가 대상 건은 5개 구분항목 중 앞 3개 항목의 점수를 모두 조회할 수 있어야
    소계가 표시된다. 나머지 항목(가점·감점 성격)은 소계 표시 여부에 영향을 주지 않는다.


(3) 평가위원 지정
1. 각 평가항목에 대한 평가위원을 지정하기 위해 평가위원 입력 후 사용자 검색 버튼을 클릭한다.
2. [통보] 버튼을 클릭하여 검색된 평가위원들을 대상으로 평가요청 메일을 발송한다.

Check Point
1. 계약의뢰서 등록시점에 지정된 평가위원이 기본 평가위원으로 지정된다.
2. 평가위원 검색 후 반드시 통보 버튼을 클릭해야만 평가요청 메일이 발송된다.
3. 통보시, 자동으로 평가진행 상태가 "평가중" 상태로 변경된다.
4. 평가항목 당 평가위원은 최소 1명에서 최대 3명까지 지정할 수 있으며, 모든 평가항목에 대해 최소 1명의 평가위원이라도 지정이 되어야만 통보가 가능하다.
5. 현재 날짜가 평가마감 일시보다 이후라면 모든 항목이 비활성화되어 더 이상의 수정이 불가능하다.
6. 평가완료된 평가항목인 경우에는 평가위원을 수정할 수 없다.
7. 환경안전평가 대상인 경우 환경안전 평가위원은 시스템 설정값에 따라 자동 지정되며 화면에서 변경할 수 없다.
8. 재입찰(2차 이상 입찰차수)이 진행된 건은 이 화면에서 평가위원을 새로 지정하거나 통보할 수 없으며,
   기존에 지정된 평가위원만 조회된다.
9. 통보 메일은 검색된 평가위원 전원에게 발송되며, 별도의 참조(CC)는 없다.


(4) 결과 조회
1. 낙찰업체를 선택(체크박스 클릭)한다.
2. [저장] 버튼을 클릭하여 결과를 저장한다.
3. [Submit] 버튼을 클릭하여 저장된 결과를 결재 상신한다.
4. 재입찰이 필요한 경우 [재입찰] 버튼을 클릭하여 재입찰 요청메일을 발송한다.

Check Point
1. 본 화면은 낙찰자 결정 일시 이후에 조회되는 화면이다.
2. 우선협상대상자 목록은 다음 조건일 때만 보여진다.
① 입찰업체수가 1개 이거나
② 입찰업체수가 2개 이상일 때 예상금액보다 낮게 투찰한 업체가 있는 경우이거나
③ 입찰차수가 3보다 큰 경우(즉, 3회 재입찰 이후)
3. 낙찰업체 선정하지 않고 Submit하게 되면 결재 승인이 완료된 후에 해당 입찰 건은 유찰 처리가 된다.
(입찰진행상태가 "유찰"로 변경됨)
4. 낙찰업체 선정 후 Submit하게 되면 결재 승인이 완료된 후에 해당 입찰 건은 낙찰완료 처리가 된다.
(입찰진행상태가 "낙찰완료"로 변경됨)
5. 재입찰 요청메일 발송을 하게 되면 입찰예정일(입찰마감 일시), 평가마감 일시, 낙찰자 결정 일시가 선택된
   입찰예정일 일시로 자동 변경되며 업체의 투찰 상태는 "임시저장" 상태로 변경된다.
6. 기술평가 비율과 가격평가 비율이 화면에 함께 표시되며, 계약의뢰서에서 선택한 평가 유형에 따라 결정된다.
7. 화면에 표시되는 점수 합계와 순위는 사용자가 즉시 계산하는 것이 아니라, 평가마감 일시가 지난 뒤
   시스템이 자동으로 실행하는 계산 작업을 거쳐 반영된다. 평가마감 직후에는 아직 계산 전이라
   결과가 비어 보일 수 있다.
8. [재입찰] 버튼은 시스템이 재입찰 대상이라고 판단한 경우에만 나타난다.


3.8 계약품의

(1) 계약품의 List 조회
1. 조회할 조회 조건을 입력한다.
2. [Search] 버튼을 클릭하여 계약품의 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. 상태가 미작성인 항목을 더블 클릭해 계약품의서를 등록한다. (☞ (2) 계약품의 등록 창이 나타남)
5. 상세 조회하고자 하는 항목을 더블 클릭한다.

Check Point
1. 계약형태가 "입찰"인 경우, 평가/낙찰 완료 이후에 계약품의를 진행할 수 있다.
2. 계약형태가 "수의" 또는 "변경"인 경우, 계약의뢰 이후에 바로 계약품의를 진행할 수 있다.
3. 계약품의 목록과 계약품의가 작성되지 않은 미작성 항목을 List로 조회 할 수 있다.
4. 진행상태가 결재중인 경우 본인 등록건만 조회되고 타인이 등록한 건은 조회할 수 없다.
5. 계약품의 관리자로 지정된 사용자는 타인이 등록한 결재중 건도 상세 조회할 수 있다.
6. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(2) 계약품의 등록
1. 계약형태에 따른 계약정보를 입력한다.
2. 계약형태에 따른 파일을 첨부한다.
3. [저장] 버튼을 클릭하여 입력 사항을 저장할 수 있다.
4. [삭제] 버튼을 클릭하여 저장된 계약정보를 삭제한다.
5. [Submit] 버튼을 클릭하여 저장된 계약품의 정보를 결재 상신한다.

Check Point
1. [저장] 버튼은 신규 작성이거나, 진행상태가 작성중·상신취소·결재반려이면서 등록자 본인인 경우에만 활성화된다.
2. [삭제], [Submit] 버튼은 진행상태가 작성중이면서 등록자 본인인 경우에만 활성화된다.
3. 계약형태에 따라 입력해야 하는 계약정보와 첨부파일이 다르며, 입찰인 경우와 수의/변경인 경우 화면이 다르게 나타난다.
4. 결재 상신 이후에는 계약품의 정보를 수정할 수 없다.
5. 계약품의가 완료되면 계약의뢰 List에서 계약서 첨부파일을 다운로드할 수 있다.


3.9 계약현황

(1) 계약진척현황
1. 공사명, 공사코드, 계약형태, 계약담당자, 의뢰자, 검토요청일 기간, 대공종, 구분(전체 / 진행중 /
   유찰 / 완료)을 조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 계약진척현황을 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

Check Point
1. 계약진척현황은 등록된 전체 계약의뢰건이 조회되며, 계약의뢰 / 사전보고 / 입찰안내서 /
   현장설명서 / 현장설명회결과 / 입찰 / 계약품의 각 단계의 진행상태가 아이콘(미진행 / 진행중 /
   완료 / 유찰)으로 표시된다.
2. '구분' 조회 조건에서 진행중·유찰·완료 중 하나를 선택하면 해당 상태의 건만 걸러서 조회할 수
   있다. 건수 집계 요약이 화면에 따로 표시되지는 않는다.


(2) 계약진척현황 조회
1. 공사명, 공사코드, 계약형태, 계약담당자, 의뢰자, 검토요청일 기간, 대공종, 구분(전체 / 진행중 /
   유찰 / 완료)을 조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 계약진척현황을 조회한다.
3. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

Check Point
1. 계약진척현황과 동일한 조회 조건과 항목을 조회 전용으로 제공하는 화면이며, [Reset] 버튼은 없다.


(3) Area별 계약현황
1. 등록일 기간을 조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 Area별 계약현황을 조회한다.
3. "전체" 탭에서는 Area와 계약형태를 함께 묶은 전체 현황을 하나의 표에서 확인한다.
4. "Area별" 탭에서는 Area마다 계약형태별 진행·완료 건수와 진행율을 별도의 표로 확인한다.

Check Point
1. Area는 기흥, 화성, 온양, 중국, 미국, 평택 6개로 구분되어 집계된다.
2. [Excel 저장] 버튼은 "전체" 탭에서만 제공되며 "Area별" 탭에는 없다.


(4) 유형별 계약현황
1. Area, 등록일 기간을 조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 유형별 계약현황을 조회한다.
3. [환율] 버튼을 클릭하여 년도별 환율을 조회한다.
4. '계약체결(건)' 항목을 더블 클릭하면 그 구분에 속한 계약 건의 상세 내역을 팝업으로 확인한다.

Check Point
1. 계약유형별 통계는 계약의뢰와 계약품의가 모두 완료된 건을 대상으로 집계한다. 조회 조건의
   Area는 집계 대상을 좁히는 조건일 뿐, 결과를 Area별로 나누어 보여주지는 않는다.
2. 계약형태(입찰 / 수의 / 변경)별, 관계사·비관계사·전체 구분별로 계약체결 건수, 점유율,
   계약금액, 예산, 효율화 금액(절감액), 절감률이 집계되어 표시된다.
3. 소계 행은 입찰과 수의 계약만 합산하고 변경계약은 제외하며, 총계 행은 변경계약까지 포함한다.
   그래서 소계와 총계의 건수·금액이 다를 수 있다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(5) 상태별 계약현황
1. 계약형태, 등록일 기간을 조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 상태별 계약현황을 조회한다.

Check Point
1. Area별로 계약의뢰서, 사전보고, 안내서발송, 현장설명회, 현장설명회결과, 입찰/평가, 계약품의
   각 단계의 진행 건수를 한 화면에서 확인할 수 있다. 건수 단위로 집계되므로 [환율] 버튼은
   제공되지 않는다.
2. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(6) 월별 계약현황
1. 대상년도를 조회 조건으로 선택한다.
2. [Search] 버튼을 클릭하여 월별 계약현황을 조회한다.
3. [환율] 버튼을 클릭하여 년도별 환율을 조회한다.
4. 건수가 표시된 월별 항목을 더블 클릭하여 해당 월의 계약 상세 내역을 팝업으로 조회한다.
5. 상세 내역 팝업에서는 관계사구분, 계약형태(입찰 / 수의 / 변경), 이전계약 포함 여부,
   WBS COST 포함 여부를 다시 선택해 내역을 좁혀볼 수 있고 [Excel 저장]으로 따로 저장할 수 있다.

Check Point
1. 계약형태별, 관계사·비관계사·전체 구분별로 건수와 금액이 월 단위로 집계된다. 소계는 입찰과
   수의만, 총계는 변경계약까지 포함하여 집계한다.
2. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(7) 입찰 진행현황
1. 조회할 조회 조건(현장설명회 일자, 입찰마감 일자, 공사명, 공사코드, 관리번호, 업체카테고리,
   입찰담당자)을 입력한다.
2. [Search] 버튼을 클릭하여 입찰 진행현황을 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

Check Point
1. 업체선정방식이 입찰이며 계약의뢰와 계약사전보고가 모두 결재완료된 건이 조회된다.
2. 계약사전보고 관리번호, 공사코드/공사명, 입찰담당자, 예정가, 현장설명회 일시, 입찰마감 일시,
   입찰방식, 업체별 참여여부, 입찰안내 발송일뿐 아니라 제출가, 평가점수, 순위, 낙찰일자,
   낙찰자 여부까지 참여 업체 단위로 한 화면에서 확인할 수 있다.
3. 입찰방식은 계약의뢰서의 기술평가 여부와 환경안전평가 여부에 따라 가격 / 가격-기술 / 가격-환안 /
   가격-기술-환안으로 표시된다.
4. 조회 기간의 기본값은 현재일 기준 최근 12개월이다.


3.10 업체관리

(1) 업체 List 조회
1. 업체명, 업태, 신용등급 유효기간, 거래가능여부, 등록자, 등록일, 업체 카테고리(대·중·소분류)를
   조회 조건으로 입력한다.
2. [Search] 버튼을 클릭하여 업체 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.
5. [등록] 버튼을 클릭하면 업체 등록 화면이 새 창으로 열린다.
6. 상세 조회하고자 하는 업체를 더블 클릭하면 해당 업체의 상세 화면이 새 창으로 열린다.

Check Point
1. 등록일은 필수 조회 조건이며 값이 없으면 조회되지 않는다. 화면을 처음 열면 등록일은 최근
   12개월, 신용등급 유효기간은 당일부터 12개월 후까지가 기본값으로 채워진다.
2. List에는 관리번호, 업체명, 사업자등록번호, 업태, 신용등급 유효기간, 업체 카테고리,
   거래가능여부, 입찰가능여부, 등록자, 등록일, 진행상태가 표시된다.
3. 업체 담당자로 접속하면 자신이 속한 업체 정보만 조회되고, 삼성 반도체 소속 사용자나 시스템
   관리자 권한이 있으면 전체 업체가 조회된다.


(2) 업체 등록
1. 업체 List에서 [등록] 버튼을 클릭하여 업체 등록 화면을 연다.
2. 사업자구분(법인 / 개인), 업체규모, 법인등록번호, 사업자등록번호, 설립일자, 주소, 팩스,
   거래가능여부, 입찰가능여부를 입력한다.
3. 보유면허를 최대 5건까지 선택하고 각 면허의 등록번호를 입력한다.
4. 신용등급, 평가기관, 평가시점, 유효기간과 시공능력평가(토건·토목·건축 순위와 금액, 평가시점)를
   입력한다.
5. 대기업관련건설사여부, 특수관계인여부를 선택하고 관련 첨부파일을 등록한다.
6. [저장] 버튼을 클릭하여 입력한 내용을 저장한다.
7. [Submit] 버튼을 클릭하여 저장된 업체 정보를 결재 상신한다.

Check Point
1. 업체코드, 대표자명, 업태, 대표전화는 화면에서 직접 입력할 수 없고 조회된 값이 표시된다.
2. 사업자등록번호·법인등록번호·팩스 번호는 형식이 맞지 않으면 저장되지 않는다. 거래가능여부를
   '불가능'으로 선택하면 거래중지 사유를 반드시 입력해야 한다.
3. 보유면허는 면허 종류만 선택하고 등록번호를 비워둘 수 없으며, 같은 면허를 중복 선택할 수 없다.
4. 신용등급 유효기간은 평가시점보다 이전일 수 없다.
5. 업체 카테고리(대·중·소분류)는 이 화면에서 등록·수정되지 않고 조회 조건과 List 표시에만
   사용된다. ※ 확인 필요 — 카테고리를 지정하는 화면은 확인되지 않았다.


(3) 업체 정보 조회 / 수정
1. 업체 List에서 조회할 업체를 더블 클릭하여 상세 화면을 연다.
2. 등록된 기본정보, 보유면허, 신용등급, 시공능력평가, 첨부파일을 확인한다.
3. 작성중 상태인 업체는 내용을 수정한 뒤 [저장]하거나 [Submit]으로 결재를 상신할 수 있고,
   [삭제]로 등록을 취소할 수 있다.
4. 결재가 완료된 업체는 등록자 본인에 한하여 [등록정보 변경] 버튼을 클릭해 내용을 새로 입력하고
   다시 결재를 받을 수 있다.

Check Point
1. 버튼은 진행상태에 따라 다르게 나타난다.
   - 신규 작성 중  : [저장]
   - 작성중(저장됨) : [저장] [삭제] [Submit]
   - 결재완료       : [등록정보 변경] (등록자 본인에게만 나타난다)
   - 그 밖의 상태(상신중·반려·상신취소) : 버튼이 없고 조회만 가능하다
2. 결재가 완료된 이후에는 기존 항목을 직접 고칠 수 없고, [등록정보 변경]으로 새로 등록해야 한다.
3. 첨부파일은 상신취소 상태에서도 등록·수정할 수 있다.


(4) 업체 담당자 정보 변경
1. 업체 상세 화면 아래쪽의 담당자 정보에서 담당자명, 부서, 직급, 이메일, 전화, 휴대폰, 팩스를
   입력하거나 수정한다.
2. [저장] 버튼을 클릭하여 담당자 정보만 별도로 저장한다.

Check Point
1. 담당자 정보 [저장] 버튼은 결재가 완료된 업체에서, 시스템에 지정된 일부 담당 계정에만
   나타난다. 그 외 사용자에게는 담당자 정보가 조회만 되고 버튼이 보이지 않는다.
2. 담당자 정보 저장은 (2)·(3)의 결재 절차와 무관하게 즉시 반영된다.


# 4. 현장설명서 검토담당자   ※ 현행 미사용 — 참고용

■ 현장설명서 화면이 현행 CPMS 메뉴에서 내려갔으므로 이 역할도 현재는 사용되지 않는다.
  현장설명서를 등록하지 않아도 이후 단계가 모두 정상 진행되며, 질의응답·입찰·평가·
  계약품의 어느 단계도 현장설명서를 필요로 하지 않는다.
  향후 현장설명서 화면이 다시 열릴 경우를 대비해 절을 남겨 둔다. (3.4 (1) 안내 참조)

이 장은 계약진행자가 등록한 현장설명서를 **검토**하도록 지정된 사용자를 위한 것이다.
역할관리에서 부여하는 권한이 아니라, 계약진행자가 현장설명서 등록 화면에서 검토항목별로
사람을 지정하면 그 사람에게만 검토 버튼이 나타난다. 지정 대상은 두 가지다.

  검토자        : 검토 진행상태와 검토결과를 **입력**할 수 있다.
  참조(부서장)  : 목록에서 해당 건을 **조회만** 할 수 있다. 입력은 할 수 없다.

검토항목은 시공 / 기성 / 보안 / 환경 / 법무 5가지이며, 항목마다 검토자와 참조를 따로 지정한다.

4.1 현장설명서 검토 경로
계약관리 > 현장설명회 관리 > 현장설명서 List
(계약진행자와 같은 메뉴를 사용한다. 별도의 검토자 전용 메뉴는 없다.)

4.2 CPMS 업무 프로세스

(1) 현장설명서 List 조회
1. 계약진행자가 [검토요청]을 누르면 검토요청 메일을 수신한다.
2. 현장설명서 List에서 해당 건을 조회한 뒤 더블 클릭하여 상세 화면으로 진입한다.

Check Point
1. 검토자 또는 참조(부서장)로 지정되면, 결재완료 전이라도 해당 건이 목록에 조회된다.
   (그 외 사용자는 결재완료된 건과 본인이 등록한 건만 보인다.)
2. 목록 화면에 들어가는 것 자체는 누구나 가능하다. 건이 보이고 안 보이는 것은
   본인이 검토자·참조·등록자인지, 또는 결재가 완료되었는지에 따라 정해진다.


(2) 현장설명서 검토
1. [현장설명서 보기] 버튼을 클릭하여 계약진행자가 첨부한 현장설명서를 다운로드한다.
2. 진행상태를 '검토중' 또는 '검토완료'로 선택한다.
3. 검토결과를 입력한다.
4. [결과저장] 버튼을 클릭하여 검토 결과를 저장한다.

Check Point
1. [현장설명서 보기], [결과저장] 버튼은 본인이 **검토자**로 지정된 경우에만 나타난다.
   참조(부서장)로만 지정된 사용자에게는 두 버튼이 모두 나타나지 않는다.
2. 진행상태와 검토결과 입력칸은 다음 중 하나라도 해당하면 잠긴다.
   - 로그인 ID가 그 행의 검토자와 다를 때
   - 현장설명서 전체 상태가 완료(COMPLETED)일 때
   - **그 행의 검토상태를 이미 '검토완료'로 저장했을 때**
   즉 한 번 검토완료로 저장하면 본인도 다시 수정할 수 없다. 검토중 상태로 저장해 두면
   완료 전까지 계속 수정할 수 있다.
3. 필수(*) 표시는 로그인자가 해당 행의 검토자인 경우에만 나타난다.
4. 검토결과는 최대 333자까지 입력할 수 있다.
5. 계약진행자가 현장설명서를 [완료] 처리하면 검토 버튼이 모두 사라진다.


# 5. 기술평가위원

이 장은 계약의뢰서에서 **기술평가 항목별 평가위원으로 지정된** 사용자를 위한 것이다.
역할관리로 부여하는 권한이 아니며, 계약의뢰자가 계약의뢰서를 작성할 때 항목마다 사람을
지정해야 생긴다. 항목은 4개이고 항목마다 다른 사람을 지정할 수 있다.
  공사수행능력 / 공정관리 / 품질관리 / 안전환경
본인이 지정된 항목만 점수를 보고 입력할 수 있으며, 다른 항목의 점수는 볼 수 없다.
환경안전 평가는 담당자 지정 방식이 다르므로 「6. 환경안전 평가위원」을 참조한다.

5.1 평가/업체선정 경로
계약관리 > 평가/업체선정

5.2 CPMS 업무 프로세스

(1)평가/업체선정 List 조회

Search 버튼을 클릭하여 평가/업체선정 List를 조회한다.
2. Reset 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
3. 업체 기술평가하고자 하는 평가 건을 더블 클릭한다. (☞ (2) 평가 등록 창이 나타남)

Check Point
1. 본인이 평가위원으로 지정된 평가 건과, 이미 결재완료된 평가 건이 함께 조회된다. 결재완료된
   건은 평가위원 지정 여부와 관계없이 공개되며, 다른 담당자가 아직 작성 중인 건은 보이지 않는다.
2. 평가를 완료하면 본인 담당 항목의 평가진행현황이 “평가완료”로 변경된다.
3. Excel 저장 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.
4. 목록에 나타나려면 투찰(입찰서류 제출) 마감 일시가 지나 있어야 한다.


(2) 평가 등록
1. 기술항목 평가 아이콘을 클릭하여 업체 기술평가를 진행한다. (☞ (3) 기술항목 평가 창이 나타남)

Check Point
1. 본인이 담당하고 있는 평가항목에 대해서만 아이콘이 보여지며, 담당 외 평가항목 점수는 조회할 수 없다.
2. 반드시 평가마감 일시 전까지 업체 기술평가를 완료해야한다.
3. 업체명은 AA, BB, CC …와 같이 익명으로 표시되며 실제 업체명은 확인할 수 없다.


(3)기술항목 평가

아이콘을 클릭하여 업체가제출한 기술평가 서류를 다운로드한다.
2. 업체 제출서류에 근거하여 등급 또는 점수를 입력한다. (안건에 따라 입력 방식이 다르다.
   아래 Check Point 3 참조)
3. 필요하면 평가의견을 작성하고 평가 근거자료를 첨부한다.
4. 입력을 마친 뒤 평가 등록 버튼을 클릭하여 업체 기술평가를 완료한다.

Check Point
1. 소계는 자동 합산되며, 평가완료(평가 등록 버튼 클릭) 후에는 재 평가를 할 수 없다.
2. 평가기준은 각 평가항목별로 정의된 기준을 보여주며 평가위원이 수정할 수 없다.
3. 안건에 따라 점수 입력 방식이 다르다. 이전 방식은 항목별로 A~E 등급을 입력하면 자동으로
   가중치·점수로 환산되고, 최신 방식은 항목별 점수를 숫자로 직접 입력한다. 화면에 나타나는
   입력란 형태를 그대로 따르면 된다.
4. 이 화면에는 임시저장 기능이 없다. 등록 버튼을 누르는 즉시 평가가 완료 처리되므로,
   모든 항목을 입력한 뒤에 등록 버튼을 클릭한다.
5. 평가를 등록하면 입찰담당자에게 완료 안내 메일이 발송되며, 같은 항목의 다른 평가위원 중
   본인을 제외한 최대 2명이 참조로 함께 포함된다.


# 6. 환경안전 평가위원

이 장은 **환경안전 평가만** 담당하는 사용자를 위한 것이다. 기술평가위원과 달리 계약의뢰서에서
건별로 사람을 지정하는 방식이 아니라, **시스템에 등록된 환경안전 평가 담당자 1명**만이
이 역할을 수행한다. 담당자 본인이 아니면 평가 아이콘 자체가 나타나지 않으며,
담당자를 변경하려면 시스템 담당자에게 요청해야 한다.

6.1 평가/업체선정 경로
계약관리 > 평가/업체선정 (기술평가위원과 동일한 메뉴·동일한 List 화면을 사용한다)

6.2 CPMS 업무 프로세스

(1) 평가/업체선정 List 조회
1. [Search] 버튼을 클릭하여 평가/업체선정 List를 조회한다.
2. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
3. 환경안전 평가하고자 하는 평가 건을 더블 클릭한다. (☞ (2) 환경안전항목 평가 창이 나타남)

Check Point
1. 목록 화면은 기술평가위원과 동일하다(5.2 (1) 참조). 환경안전 평가위원 전용 목록은 없다.
2. 본인이 환경안전 평가위원으로 지정된 건은 결재완료 여부와 관계없이 목록에 나타난다.
   지정되지 않았고 담당자 본인도 아니라면 결재가 완료된 건만 보인다.
3. 평가 아이콘은 목록이 아니라 평가 등록 화면에 들어가야 확인할 수 있다.
4. 목록에 나타나려면 투찰(입찰서류 제출) 마감 일시가 지나 있어야 한다.


(2) 환경안전항목 평가
1. 아이콘을 클릭하여 업체가 제출한 환경안전 평가 서류를 다운로드한다.
2. 업체 제출서류에 근거하여 환경안전 평가항목별 점수를 입력한다. 기술평가와 달리 등급이 아니라
   숫자 점수를 직접 입력한다.
3. 필요하면 평가의견을 작성하고 평가 근거자료를 첨부한다.
4. 입력을 마치지 못했으면 [임시저장]으로 중간 저장할 수 있다. 모든 항목의 입력을 마치면
   [평가 등록] 버튼을 클릭하여 환경안전 평가를 완료한다.

Check Point
1. 환경안전항목 평가는 계약의뢰서에서 환경안전평가 대상으로 선택된 건에 대해서만 나타난다.
2. 로그인 ID가 설정파일의 환경안전 평가 계정과 같아야 평가 아이콘이 보인다. 역할관리에서
   권한을 부여하는 방식이 아니므로, 다른 계정으로는 아무리 권한을 줘도 보이지 않는다.
3. [임시저장]은 몇 번이든 다시 할 수 있으나, [평가 등록]으로 완료 처리한 뒤에는 재 평가를 할 수 없다.
4. 환경안전 평가는 평가구분 항목이 여러 개여도 **평가위원은 모두 동일인**이다.
5. 입찰담당자 본인도 평가상태가 '등록(REG)'인 경우에는 같은 아이콘이 보인다.
6. 안건에 따라 화면 구성이 두 가지다. 세부 평가항목별로 점수를 입력하면 자동 합산되는 화면과,
   업체별 총점 하나만 입력하는 화면이 있다. 어느 쪽이든 등급이 아니라 숫자 점수를 입력한다.
7. 세부 항목별로 입력하는 화면에서는 구분항목 5개 중 앞 3개 항목의 점수를 모두 조회할 수 있어야
   소계가 표시된다. 나머지 항목(가점·감점 성격)은 소계 표시 여부에 영향을 주지 않는다.
8. 평가 등록을 완료하면 입찰담당자에게 완료 안내 메일이 발송된다. 환경안전 평가위원은 1명뿐이라
   참조로 넣을 다른 평가위원이 없으므로 참조는 지정되지 않는다.

Check Point

# 8. 업체담당자

Check Point

2. 업체담당자에게는 [등록] 버튼이 나타나지 않으며 [Excel 저장] 버튼만 제공된다.


(2) 입찰참여의사 등록
1. 입찰 정보 확인 후, 입찰 참여 여부를 선택한다.
2. [참여여부 회신] 버튼을 클릭한다.

Check Point
1. 참여등록 마감 일시 전에 참여여부 회신을 하지 않았다면 입찰에 참여하지 않음으로 간주된다.

3. 회신이 완료되면 입찰담당자에게 참여여부 회신 메일이 자동 발송된다.

Check Point
1. 입찰담당자로부터 답변 등록 완료 메일을 수신한 후에 해당 공사에 대한 답변을 List에서 조회할 수 있다.
2. 본인이 등록한 질의와 그에 대한 입찰담당자의 답변만 조회할 수 있으며 다른 업체가 등록한 질의는 조회할 수 없다.
3. 업체담당자로 지정되지 않은 사용자는 [질의등록] 버튼을 사용할 수 없다.
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.

4. [임시저장] 버튼을 클릭하여 질의 정보를 저장한다.
5. [삭제] 버튼을 클릭하여 저장된 질의 정보를 삭제한다.
6. [질의등록] 버튼을 클릭하여 저장된 질의 정보를 등록(확정)한다.

1. 모든 필수 입력항목(*)을 입력해야 임시 저장/질의 등록이 가능하다.
2. [삭제], [질의등록] 버튼은 최초 저장 이후에 보여진다.
3. 입찰참여여부 회신 및 현장설명회에 참석한 업체만 해당 입찰공사에 대해 질의 등록할 수 있다.
4. 공사명을 선택하면 입찰공사 및 입찰수행 정보가 세팅된다.
5. 질의가 이미 등록된 입찰공사는 선택할 수 없다. (1개의 입찰공사에 대해 1개의 질의만 등록 가능)
6. 임시저장 이후에는 다른 입찰공사로 변경할 수 없다.
7. 질의 등록 버튼 클릭 후에는 질의 정보를 수정할 수 없다.


8.3 입찰등록

(1) 입찰 List 조회
1. 등록자 항목에 등록자(투찰자) 명을 검색하여 입력한다.
2. [Search] 버튼을 클릭하여 입찰 List를 조회한다.
3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. 미입찰 상태의 행을 더블 클릭하여 입찰공사에 대한 투찰을 진행한다.
5. 임시 저장 중이거나 투찰 완료한 건을 더블 클릭하여 상세 조회한다.

Check Point
1. 임시 저장 중이거나 투찰 완료한 건을 더블 클릭하면 Password 확인 창이 나타난다.
투찰 시 입력했던 Password와 다르면 투찰 정보 수정 및 조회를 할 수 없다.
2. 본인이 임시저장 또는 투찰한 건만 상세 조회가 가능하며, 다른 업체의 투찰 정보는 조회할 수 없다.
3. 재입찰의 경우에도 동일한 절차로 투찰한다. (재입찰할 때마다 입찰차수 1씩 증가. 최초 입찰차수는 0)
4. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel로 저장한다.


(2) 투찰
1. 입찰 금액을 입력한다.
2. Password를 입력한다. (향후 조회/수정 시 필요)
3. 입찰내역서, 공사수행능력, 공정관리, 품질관리, 안전/환경관리 평가 서류를 첨부한다.
4. [임시저장] 버튼을 클릭하여 입력 및 첨부한 정보를 임시 저장한다.
5. [삭제] 버튼을 클릭하여 임시 저장한 투찰 정보를 삭제한다.
6. [투찰] 버튼을 클릭하여 투찰을 완료한다.

Check Point
1. 모든 필수 입력항목(*)을 입력 및 첨부해야 임시 저장/투찰이 가능하다.
2. 입찰참여여부 회신 및 현장설명회에 참석한 업체만 해당 입찰공사에 대해 투찰할 수 있다.
3. [임시저장] 버튼은 미투찰 또는 임시저장 상태이고 입찰마감 일시가 경과하지 않은 경우에만 활성화된다.
4. [삭제] 버튼은 임시저장 상태이고 입찰차수가 0이며 입찰마감 일시가 경과하지 않은 경우에만 활성화된다.
5. [투찰] 버튼은 임시저장 상태이고 입찰마감 일시가 경과하지 않은 경우에만 활성화된다.
6. 이미 투찰한 입찰공사는 재투찰할 수 없다. (1개의 입찰공사에 대해 투찰 1회 가능)
7. [투찰] 버튼 클릭 후에는 투찰 정보를 수정할 수 없다.


# 9. 신규업체 등록 프로세스
9.1 신규업체 등록 사유
1. 기존 협력사보다 품질, 가격, 납기 측면에서 우수하다고 판정된 경우
2. 현업 검토 결과, 기존 협력사에서 제조, 납품 불가로 판정된 경우
3. 분사, 합병 등으로 기존 협력사가 존재하면서 별도의 회사가 설립된 경우
4. 당사의 일시적인 필요성 및 협업의 요구에 의해 등록이 필요한 경우
9.2 기본등록조건
1. 재무/기술/환경안전 관련 7개 항목에 대해 기준을 만족한 업체에 한하여 등록이 가능
Check Point
1. 등록자격요건 검토결과 미달항목이 있는 경우 예외등록사유서 작성 및 Knox결재필요
- 전결규정 : [기안] 현업담당자, [결재]현업임원, [통보]구매담당자
2. 환경안전항목(면허/인허가, 환경안전사전평가) 미달시에는 신규등록불가

※ 9장은 시스템 화면이 아닌 사내 업무 절차 규정이다.


9.3 등록프로세스
(1) 신규협력사 등록프로세스
협력사 발굴 단계에서는 요청부서/계약부서 협업으로 진행
   * 신규협력사의 업무에 따라 발굴단계에서 1.5 (2)의 계약담당자와 협업 진행
2. 요청부서에서 발굴된 업체에 대한 등록자격요건 7개 필수항목에 대해 사전 검토
   * 필수항목 불만족 시 예외등록사유서 작성 및 요청부서(임원)결제 필요
     단, 필수항목 중 면허/인허가, 환경안전평가 기준미달시 등록불가
3. 요청부서에서 신규업체등록의뢰서를 작성하고 Knox품의 진행
- 품의시 ‘업무위탁계획서’, ‘환경안전평가결과’, ‘신규업체보안평가요청서’,‘예외등록사유서결제본(해당시)’ 첨부

- 결재 전결규정 : [기안] 현업담당자, [결재]현업팀장, [통보]구매담당자

   * 필수항목 불만족 시 예외등록사유서 작성 및 현업(임원)결제 필요

부록 A. 이전 매뉴얼 대비 변경 사항

아래 항목은 현재 시스템을 확인하여 이전 매뉴얼과 달라진 것으로 확인된 내용이다.
이전 매뉴얼을 보고 업무하던 사용자는 이 부분만 확인해도 된다.

1. 계약의뢰 조회 전용 역할 추가
   이전에는 등록자(의뢰부서)와 구매부서만 계약의뢰를 조회할 수 있었으나, 조회 전용 역할이 추가되어
   해당 역할 보유자는 구매팀과 동일하게 검토요청 이후 상태의 의뢰를 조회할 수 있다.

2. 계약사전보고 상세 접근 권한 강화
   계약사전보고 상세 화면은 삼성전자 소속이면서 삼성전자 임직원 역할과 구매부서 역할을
   모두 보유한 사용자만 진입할 수 있으며, 그 외에는 권한 없음 화면으로 이동한다.

3. 입찰안내서 발송 위치 변경
   이전 매뉴얼의 별도 '입찰안내 발송' 화면 대신, 계약사전보고 상세 화면의 대상업체 영역에서
   [안내서 발송] / [발송이력] 버튼으로 수행한다. 참여등록 마감일시가 지나면 버튼이 사라진다.

4. 입찰 List 조회 권한 변경
   삼성전자 사용자 중 구매부서 권한이 없는 사용자(의뢰팀 등)에게는 입찰 List가 조회되지 않는다.
   투찰 상세는 업체의 경우 본인 등록건만, 구매부서의 경우 입찰중을 제외한 상태에서 입찰담당자 본인만
   조회할 수 있다.

5. 업체명 익명 처리
   평가 등록 및 기술/환경안전 평가 화면에서 낙찰업체가 확정되기 전까지 업체명이 AA, BB, CC …로
   익명 표시된다.

6. 환경안전평가 신설
   계약의뢰서에서 환경안전평가 여부를 선택할 수 있으며, 선택 시 기술평가와 별도로 환경안전 항목 평가가
   진행된다. 환경안전 평가위원은 시스템 설정값으로 지정되며 화면에서 변경할 수 없다.
   입찰방식은 가격 / 가격-기술 / 가격-환안 / 가격-기술-환안으로 구분된다.

7. 평가 등록 버튼 조건 변경
   [평가위원 지정] 버튼은 이전의 '입찰차수 0 이고 평가마감일 이전' 조건 대신, 기술평가 또는 환경안전평가
   대상 건에 대해 입찰담당자 본인인 경우 나타난다.
   [저장] 버튼은 저장 내역이 없는 경우뿐 아니라 작성중 상태에서도 평가마감 이전까지 활성화된다.

8. 계약품의 관리자 역할 신설
   업무그룹관리의 CONTAPPR_ADMIN 업무그룹에 등록된 사용자는 타인이 등록한 결재중 계약품의도
   상세 조회할 수 있다.

9. 계약현황 [환율] 버튼 제공 범위 변경
   [환율] 버튼은 유형별 계약현황과 월별 계약현황에서만 제공되며, 상태별 계약현황에는 제공되지 않는다.

10. 입찰 진행현황 화면 신설
   입찰 건의 계약사전보고 관리번호부터 입찰안내 발송일, 업체별 참여여부까지 한 화면에서 확인할 수 있는
   입찰 진행현황 화면이 추가되었다.

11. 현장설명회 결과 중복 등록 방지
   하나의 계약의뢰에 대해 현장설명회 결과는 1건만 등록할 수 있으며, 다른 사용자가 먼저 등록한 경우
   저장되지 않는다.

12. 입찰대상 공사관리 화면
   이전 매뉴얼의 '입찰대상 공사관리(입찰대상 공사 List/등록, 발주공종 조회, 입찰공사 조회)'는
   현재 메뉴 목록에 포함되어 있지 않아 본 매뉴얼에서는 제외하였다. 화면 자체는 남아 있으므로
   메뉴에 표시되는지 확인이 필요하다.

13. 매뉴얼 구성 변경 — 역할 장 2개 신설
   이전 매뉴얼에는 '현장설명서 검토담당자'가 별도 역할로 있었으나 실제 업무 설명은
   계약진행자 쪽에 섞여 있었다. 또 환경안전 평가는 기술평가와 담당자 지정 방법이 전혀
   다른데도 기술평가위원 장 안에 들어 있었다. 두 업무를 각각 독립된 장으로 분리하였다.
     4. 현장설명서 검토담당자
     6. 환경안전 평가위원
   이에 따라 그 뒤의 장 번호가 밀렸다.

14. 참조(부서장)는 검토 결과를 입력할 수 없음
   현장설명서 검토에서 참조(부서장)로 지정된 사용자는 목록에서 건을 조회만 할 수 있고,
   검토 진행상태와 검토결과는 입력할 수 없다. [현장설명서 보기]·[결과저장] 버튼이
   나타나지 않는다. 검토 입력이 필요하면 검토자로 지정받아야 한다.

15. 환경안전 평가위원은 시스템 등록 담당자 1명
   이전 매뉴얼의 "환경안전 평가위원으로 지정된 사용자"라는 표현은 계약의뢰서에서 건별로
   지정하는 것처럼 읽히나, 실제로는 시스템에 등록된 환경안전 평가 담당자 1명만 해당한다.
   다른 사용자에게 역할을 부여해도 환경안전 평가 아이콘은 나타나지 않는다.

16. '공사비검증' · '기준정보관리' 장 제외
   두 장은 해당 화면 자료가 없어 내용을 확인할 수 없으므로 목차에서 제외하였다.
   이에 따라 '신규업체 등록 프로세스'가 9장이 되었다.

17. 현장설명서 단계 제외 (현행 미사용)
   이전 매뉴얼에 있던 '현장설명서 List'와 '현장설명서 등록'은 현행 CPMS 메뉴에서 내려갔다.
   현재 현장설명회 관리 메뉴에는 '현장설명회 결과 List'만 노출된다.
   확인 결과 현장설명서를 등록하지 않아도 이후 단계가 모두 정상 진행된다.
     - 현장설명회 결과 등록 화면은 일정 초기값을 현장설명서가 아니라 계약사전보고에서 가져온다
     - 질의응답 · 입찰 · 평가/업체선정 · 계약품의 어느 단계도 현장설명서를 조건으로 걸지 않는다
     - 현장설명회 결과 목록도 현장설명서가 없으면 그 조건을 건너뛴다
   이에 따라 3.4 (1)(2)와 4장(현장설명서 검토담당자)은 참고용으로만 남겼다.
   업무 순서는 계약사전보고 → 입찰안내 → **현장설명회 결과** → 질의응답 순이 된다.
   ※ 화면 자체는 남아 있어 주소로 직접 열면 표시된다. 다시 사용하게 되면 해당 절을 되살린다.

18. '업체별 계약현황' 화면 없음
   이전 매뉴얼과 현재 시스템 어디에도 '업체별 계약현황' 화면은 존재하지 않는다.
   계약현황은 계약진척현황 / 계약진척현황 조회 / Area별 / 유형별 / 상태별 / 월별 /
   입찰 진행현황 7가지다.

19. 자동 발송 메일 안내 추가 (1.7 신설)
   업무 단계마다 자동으로 나가는 안내 메일의 발송 시점과 수신자를 한 표로 정리하였다.
   일부 메일은 처리한 담당자 본인이 아니라 시스템 대표 주소로 발송되므로 보낸사람이
   다르게 표시된다는 점도 함께 정리하였다.

20. Area 구분 정정 — '천안' → '중국'
   이전 매뉴얼의 Area별 계약현황 설명에 '천안'이 있었으나, 실제 집계 구분은
   기흥 / 화성 / 온양 / 중국 / 미국 / 평택 6개다.

21. 유형별 계약현황 집계 기준 정정
   이전 매뉴얼은 'Area별로 집계'된다고 하였으나, 실제로는 계약형태와 관계사 구분을 기준으로
   집계된다. 조회 조건의 Area는 집계 대상을 좁히는 조건일 뿐이다.
   또한 소계는 입찰·수의만 합산하고 총계는 변경계약까지 포함하므로 두 값이 다를 수 있다.

22. 환경안전 항목 평가는 등급이 아니라 점수 입력
   이전 매뉴얼은 기술평가와 같이 '등급을 입력한다'고 하였으나, 환경안전 항목 평가는
   숫자 점수를 직접 입력한다. 기술평가와 달리 [임시저장] 버튼도 있다.

23. 평가 결과는 즉시 계산되지 않음
   평가 점수 합계와 순위는 평가마감 일시가 지난 뒤 시스템이 자동으로 실행하는 계산 작업을
   거쳐 반영된다. 평가마감 직후에는 결과가 비어 보일 수 있다.

24. 평가/업체선정 목록 조회 범위 정정
   이전 매뉴얼은 '본인이 평가위원으로 지정된 건만 조회된다'고 하였으나, 결재가 완료된 건은
   평가위원 지정 여부와 관계없이 조회된다. 또한 투찰 마감 일시가 지나야 목록에 나타난다.

25. 예정가 산출 List 조회 범위 정정
   이전 매뉴얼은 '등록한 의뢰 담당자만 조회 가능'이라고 하였으나, 운영부서(전자) 사용자는
   전체를 조회할 수 있고 그 외 사용자는 본인이 산출담당자로 지정된 건만 조회할 수 있다.
   예정가 산출에는 재작성 이력 조회 화면도 있어 7.2 (3)으로 추가하였다.

26. 업체관리 절 신설 (3.10)
   이전 매뉴얼에 없던 업체 등록 / 조회·수정 / 담당자 정보 변경 절차를 추가하였다.
   담당자 정보 [저장] 버튼은 결재완료된 업체에서 시스템에 지정된 일부 계정에만 나타난다.

27. 계약의뢰서 등록 절차 복원 (2.2 (3))
   이전 매뉴얼에는 Check Point만 있고 절차가 빠져 있어 등록 절차를 채웠다.
   아울러 검토요청이 막히는 예산 검증 조건, 유찰 건의 [재의뢰] 기능, 의뢰반려 상태로
   2주가 지나면 자동 삭제된다는 점을 추가하였다.
