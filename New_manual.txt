# 1. 개요

1.6 사용자 역할 및 권한

(1) 사용자 역할 구분
CPMS의 화면 및 버튼은 로그인 사용자의 역할(Role)에 따라 조회 범위와 활성화 여부가 결정된다.

1. 삼성전자 임직원 : 소속회사코드가 삼성전자(C10)이거나 Samsung_Semi 역할이 부여된 사용자.
2. 구매(계약)부서 : Samsung_Semi_Purchase 역할이 부여된 사용자. 계약진행자 업무를 수행한다.
3. 의뢰부서(운영부서) : 계약의뢰 역할이 REQ인 사용자. 계약의뢰서/예정가 산출 의뢰를 작성한다.
4. 조회 역할 : 계약의뢰 역할이 INQ인 사용자. 등록/수정 없이 조회만 가능하다.
5. 계약품의 관리자 : 업무그룹관리의 CONTAPPR_ADMIN 업무그룹에 등록된 사용자.
6. 평가위원 : 계약의뢰서 등록 시 항목별(공사수행능력/공정관리/품질관리/안전환경)로 지정된 사용자.
7. 환경안전 평가위원 : 시스템 설정에 등록된 환경안전 평가 담당자.
8. 업체담당자 : 업체정보에 입찰담당자로 지정된 협력사 사용자.

Check Point
1. 소속회사코드가 삼성전자(C10)인 사용자는 Samsung_Semi 역할이 없어도 삼성전자 임직원으로 인식한다.
2. 한 사용자가 복수의 역할을 동시에 가질 수 있으며, 화면별로 요구하는 역할이 다르다.
3. 역할이 조회되지 않는 사용자는 DENY로 처리되어 업체 사용자와 동일하게 취급된다.

# 2. 계약의뢰자

(2)계약의뢰서 List 조회
1. 조회할 조건을 입력을 입력한다.

3. [Reset] 버튼을 클릭하여 입력한 검색 조건을 초기화한다.
4. [등록] 버튼을 클릭하여 계약의뢰서 팝업을 실행한다. (☞ (3) 계약의뢰서 등록 팝업 창이 나타남)
  * 상세 조회하고자 하는 항목 더블 클릭 (☞ (3) 계약의뢰서 등록 팝업 창이 나타남)
5. 계약품의가 완료된 의뢰에 첨부된 계약서가 있는 경우 첨부파일 팝업을 실행해 계약서를 다운받을 수 있다.

Check Point
1. 계약의뢰 List 항목은 등록자만 조회 가능하다.
2. 계약의뢰에 관한 전체 진행 사항을 확인할 수 있다.
3. [등록] 버튼은 운영부서 사용자인 경우에만 활성화 된다.
4. 계약부서인 경우 진행상태가 검토요청 상태 이후에만 계약의뢰 List 조회/상세조회 가능하다.
5. 조회 역할(INQ)이 부여된 사용자는 계약부서와 동일하게 검토요청 이후 상태의 의뢰를 조회할 수 있다.
6. [Excel 저장] 버튼을 클릭하여 현재 조회된 List를 Excel 저장할 수 있다.
